# Implementation Plan: AC-W5-01 — Task Completion Animation + Reduced Motion Fallback

**Constitutional validator:** PASS (22/22 constraints)

---

## Approach

Three CSS-only animations wired through `justCompleted` and `isNextHighlighted` props passed
from `RoadmapView` to `TaskRow`. No new packages. The `@keyframes taskHighlightPulse` and
two animation CSS classes are added to `globals.css`. `RoadmapView` tracks which task was
just completed and which is next using two `useState` values that clear via `setTimeout(600)`.
`TaskRow` applies the animated checkmark path (`strokeDasharray` + `.check-draw-path`) and
the pulse class. The existing global reduced-motion rule (`animation-duration: 0.01ms !important`)
handles the fallback for all three animation phases automatically — no JS branching needed.

## Implementation Order

### Step 1 — `globals.css`

Add `@keyframes taskHighlightPulse` in the keyframes section (alongside existing `@keyframes checkDraw`):

```css
@keyframes taskHighlightPulse {
  0%   { background-color: var(--color-bg-card); }
  40%  { background-color: var(--color-primary-subtle); }
  100% { background-color: var(--color-bg-card); }
}
```

Add CSS classes inside `@media (prefers-reduced-motion: no-preference)` block:

```css
.check-draw-path {
  animation: checkDraw 0.3s ease-out forwards;
}

.task-next-pulse {
  animation: taskHighlightPulse 0.3s ease-out;
}
```

### Step 3 — `RoadmapView.tsx`

**New state (after existing useState/store hooks):**
```typescript
const [justCompletedId, setJustCompletedId] = useState<string | null>(null)
const [nextHighlightId, setNextHighlightId] = useState<string | null>(null)
```

**`handleComplete` additions** (at the top, before existing optimistic logic):
```typescript
const handleComplete = async (taskId: string) => {
  if (!roadmapData) return
  const previousData = roadmapData

  // Compute next priority task before optimistic update
  const nextTask = priorityTasks.find(t => t.taskId !== taskId)
  setJustCompletedId(taskId)
  setNextHighlightId(nextTask?.taskId ?? null)
  setTimeout(() => {
    setJustCompletedId(null)
    setNextHighlightId(null)
  }, 600)

  // ... existing optimistic update logic unchanged
```

**TaskRow renders** — add props wherever TaskRow is rendered (PrioritySection + PhaseSection loops):
```tsx
<TaskRow
  key={task.taskId}
  task={task}
  priority={...}
  onClick={...}

  isNextHighlighted={nextHighlightId === task.taskId}
/>
```
