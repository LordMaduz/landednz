# Research: AC-2-11 — Daily priority recalculation job

## Understanding

Build a recalculation job that re-scores all users' roadmap entries using today's `currentDate`. This is how time-sensitive urgency bonuses stay fresh — a score computed at onboarding becomes stale as months pass.

The spec says "can be triggered manually via admin endpoint at MVP" — meaning no cron scheduler is needed; just a `POST /admin/recalculate` endpoint that runs the job synchronously.

**What the job does (for each user):**
1. Fetch profile (personaKey + arrivalDate)
2. Fetch all non-COMPLETE roadmap entries
3. Fetch all tasks with dependencies
4. `resolveBlockedTasks()` → `scoreTask()` for every non-COMPLETE task using today's date
5. Write updated `isBlocked` + `priorityScore` back to DB

**AC verification:** T16 score increases when a user's `arrivalDate` is set to 10 months ago. At month 10–11 (days 275–336), T16 gets a +30 urgency bonus. Score goes from 65+5+0=70 → 65+5+30=100.

**Test approach:**
1. Create user with recent arrivalDate (today) → T16 has no urgency → score = 70
2. Update arrivalDate to 10 months ago in DB
3. Run recalculate job
4. T16 score = 100 (urgency fires)
