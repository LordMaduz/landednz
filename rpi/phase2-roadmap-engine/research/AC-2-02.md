# Research: AC-2-02 — resolveBlockedTasks() T08 blocked when T07 incomplete

## Understanding

AC-2-02 requires implementing `resolveBlockedTasks()` in `apps/api/src/core/dependencies/resolver.ts`
using TDD. The function takes a list of tasks with their dependency edges and a set of completed
task IDs, then returns a `ResolvedTask[]` array indicating which tasks are blocked and by what.

A task is `isBlocked: true` only when at least one HARD dependency is not in `completedTaskIds`.
SOFT dependencies never cause blocking.
