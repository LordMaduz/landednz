## Approach

Implement `resolveBlockedTasks()` and `getAffectedTasks()` as pure functions in
`apps/api/src/core/dependencies/resolver.ts` using strict TDD. Tests written first
(RED), then implementation (GREEN). Zero framework dependencies.

`resolveBlockedTasks()` iterates every task, inspects its dependency edges, and marks
it blocked only when at least one HARD dependency prerequisite is not in `completedTaskIds`.
SOFT dependencies are ignored entirely. Returns `ResolvedTask[]` with `taskId`, `isBlocked`,
and `blockingTaskIds` (only the unmet HARD dep IDs).

`getAffectedTasks()` finds all tasks that are direct dependents of a given completed task ID —
used for targeted recomputation rather than full roadmap rebuild.

AC-2-02 verified by T08→T09 scenario: T08 not in completedTaskIds → T09 `isBlocked: true`.
AC-2-03 verified by same pair: T08 added to completedTaskIds → T09 `isBlocked: false`.

**Key insight from research:** T07→T08 is SOFT (confirmed by human). AC-2-02/03 use T08→T09
(unambiguously HARD) to test the blocking mechanism correctly.

## Test Strategy

**resolveBlockedTasks() unit tests:**
- Task with no dependencies → `isBlocked: false`, `blockingTaskIds: []`
- Task with one HARD dep, dep incomplete → `isBlocked: true`, `blockingTaskIds: [depId]`
- Task with one HARD dep, dep complete → `isBlocked: false`, `blockingTaskIds: []`
- Task with SOFT dep incomplete → `isBlocked: false` (SOFT never blocks)
- Task with multiple HARD deps, one incomplete → `isBlocked: true`, only unmet dep in `blockingTaskIds`
- Task with multiple HARD deps, all complete → `isBlocked: false`, `blockingTaskIds: []`
- **AC-2-02:** T08 not complete → T09 `isBlocked: true`, `blockingTaskIds: ["T08"]`
- **AC-2-03:** T08 in completedTaskIds → T09 `isBlocked: false`, `blockingTaskIds: []`
- All tasks returned in result (not just blocked ones)
- Empty task list → empty result

**getAffectedTasks() unit tests:**
- Completing T08 → returns T09 (HARD), T10 (SOFT), T20 (HARD) as affected tasks
- Task with no dependents → returns []
- Unknown completedTaskId → returns []

Verification command: `npm run test:run -- apps/api/src/core/dependencies/resolver.test.ts`
