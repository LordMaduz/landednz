## Approach

`bulkOverride(userId, taskIds, currentDate)` added to `roadmap.service.ts`. It fetches all current `UserRoadmapEntry` records, splits requested IDs into `toMark` (in roadmap, not COMPLETE) and `skipped` (in roadmap, already COMPLETE), silently ignores IDs not in the roadmap. Marks `toMark` entries COMPLETE with `completionMethod: BULK_OVERRIDE`. Then runs **full recomputation** — `resolveBlockedTasks()` + `scoreTask()` for every non-COMPLETE entry (not targeted like `completeTask()`) because multiple simultaneous completions can cascade through the dependency graph in ways that per-task `getAffectedTasks()` would miss. Calls `getRoadmap()` for updated topThree. Returns `{ marked, skipped, newTopThree }`.
