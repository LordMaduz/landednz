# Implementation Plan: AC-2-10 — GET /roadmap/tasks/:taskId — 403 for PREMIUM task, unsubscribed user

## Approach

Add `GET /roadmap/tasks/:taskId` to the roadmap feature. First, migrate the `TaskContentVariant` schema to add the 3 missing scalar fields (`watchOuts`, `professionalAdviceRequired`, `professionalAdviceNote`). Then implement `getTaskDetail()` in `roadmap.service.ts`: fetch the UserRoadmapEntry (404 if absent), check `task.taskType === 'PREMIUM'` and query `Subscription.isActive` (403 if unsubscribed), then assemble `TaskDetailResponse` from Task + TaskContentVariant (personaKey fallback chain). Add `PREMIUM_REQUIRED` to `ErrorCode`. `relatedTasks` returns `[]` always (no join model in MVP). Integration tests cover all 5 paths.
