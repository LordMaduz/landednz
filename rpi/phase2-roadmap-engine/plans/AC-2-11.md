# Implementation Plan: AC-2-11 — Daily priority recalculation job

## Approach

Implement `recalculateAllRoadmaps()` in a dedicated `roadmap.recalculate.ts` service file. The function fetches all distinct userIds from `UserRoadmapEntry`, then for each user runs the same `resolveBlockedTasks` → `scoreTask` pipeline already used in `bulkOverride()`, updating every non-COMPLETE entry with the fresh `isBlocked` and `priorityScore`. Expose it via `POST /admin/recalculate` — auth checks `X-Admin-Key` against `ADMIN_API_KEY` env var (skip check if env var not set, for dev convenience). No cron scheduler — endpoint triggered manually at MVP. `config.ts` gains an optional `adminApiKey` field and `.env.example` documents the variable.
