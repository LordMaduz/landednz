## Approach

Implement `filterApplicableTasks()` and `derivePersonaKey()` as pure functions in
`apps/api/src/core/priority/filter.ts` using strict TDD. Tests written first (RED),
implementation second (GREEN).

`filterApplicableTasks()` parses three JSON string fields per task (`applicableVisaTypes`,
`applicableFamilySituations`, `applicableOccupations`) and applies AND logic: all three
must pass. A field passes if the parsed array contains `"ALL"` (no restriction) or the
user's profile value. Malformed JSON is treated as `[]` (excluded — defensive). A minimal
`FilterableTask` interface is used instead of the Prisma `Task` type — Prisma is never
imported in `core/`.

`derivePersonaKey()` maps `familySituation` to a `PersonaKey` string. Only
`familySituation` determines the result — `visaType` is NOT a parameter.
