# Research: AC-W2-09 — Auth middleware: unauthenticated → /auth/signin?redirect={path}

## Understanding

Create `apps/web/src/middleware.ts` — a Next.js Edge middleware that protects the three
app routes (`/roadmap`, `/chat`, `/settings`). When an unauthenticated request hits a
protected route, redirect to `/auth/signin?redirect={original-path}`.

**Stage 2 scope**: Routing logic only — what paths are protected and where to redirect.
No actual auth (sign in / sign out / session creation) — that's Stage 4 Supabase SSR work.

**Supabase context**: Docker is not running; `@supabase/ssr` is not installed; no `.env.local`
exists for apps/web. The full Supabase SSR integration is explicitly deferred to Stage 4 per
the CLAUDE.md dependency list. This AC must work WITHOUT Supabase running.

**Session check approach**: Use `request.cookies.getAll()` in Next.js Edge middleware to look
for any cookie with the `sb-` prefix (standard Supabase auth cookie prefix). No session cookie
= unauthenticated = redirect. This satisfies CW06 intent (cookie-based, not localStorage)
without requiring @supabase/ssr. Stage 4 will replace this one line with a proper
`createServerClient().auth.getUser()` call.

**No redirect loop**: `/auth/signin` is excluded from the middleware matcher. Confirmed
known failure point in spec: "Auth middleware redirect loop — /auth/signin must NOT be
protected, or infinite redirect."

## Functions / Routes / Tests

**Middleware structure:**
```typescript
import { NextRequest, NextResponse } from 'next/server'

const PROTECTED_PATHS = ['/roadmap', '/chat', '/settings']

export function middleware(request: NextRequest) {
  const { pathname } = request.nextUrl

  const isProtected = PROTECTED_PATHS.some(path =>
    pathname === path || pathname.startsWith(`${path}/`)
  )

  if (!isProtected) return NextResponse.next()

  // Stage 2: check for Supabase session cookie by prefix
  // Stage 4: replace with createServerClient().auth.getUser()
  const hasSession = request.cookies.getAll().some(c => c.name.startsWith('sb-'))

  if (!hasSession) {
    const url = request.nextUrl.clone()
    url.pathname = '/auth/signin'
    url.searchParams.set('redirect', pathname)
    return NextResponse.redirect(url)
  }

  return NextResponse.next()
}

export const config = {
  matcher: ['/roadmap/:path*', '/chat/:path*', '/settings/:path*'],
}
```

**Verification:**
- GET /roadmap (no cookies) → 307 redirect to /auth/signin?redirect=/roadmap
- GET /auth/signin → 200 (not protected, no redirect loop)
- GET / → 200 (marketing route, not protected)

- **Known failure point**: `/auth/signin` excluded from matcher to prevent redirect loop
