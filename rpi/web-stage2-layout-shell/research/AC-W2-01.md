# Research: AC-W2-01 — Root layout: DM Sans + DM Serif Display fonts, metadata, bg-bg background

## Understanding

The existing `apps/web/src/app/layout.tsx` is a minimal stub from Stage 1 scaffolding:
it has metadata but the `<body>` has no Tailwind classes — no background, no default font family.

This AC completes the root layout so every page inherits:
- `bg-bg` (#F8F6F3) as the page background
- `font-body` (DM Sans) as the default body font
- `font-display` (DM Serif Display) available for headings via class
- `antialiased` for smoother font rendering
- Correct `<html lang="en">` with metadata

The fonts are already self-hosted from Stage 1:
- `public/fonts/DMSans-Variable.woff2` — declared in globals.css via @font-face
- `public/fonts/DMSerifDisplay-Regular.woff2` — declared in globals.css via @font-face
- Tailwind config already maps `font-body` → DM Sans, `font-display` → DM Serif Display

No new font setup needed. This AC is purely a layout.tsx update + metadata enhancement.
