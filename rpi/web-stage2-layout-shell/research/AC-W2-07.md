# Research: AC-W2-07 — Content area: max-w-content (960px), centered, scrollable

## Understanding

AC-W2-07 is a **verification task**, not an implementation task. The content area was already built during AC-W2-03 (app layout foundation). This AC verifies that the existing content area div in `(app)/layout.tsx` correctly:

1. **Constrains width to 960px** via `max-w-content` Tailwind token
2. **Centers horizontally** via `mx-auto`
3. **Allows vertical scrolling** via `overflow-y-auto` on the main element

The task is to inspect the rendered layout at 1440px viewport width and confirm the content area is properly constrained and centered within the viewport, leaving appropriate margins on both sides.
