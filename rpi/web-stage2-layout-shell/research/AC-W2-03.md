# Research: AC-W2-03 — App layout at `/roadmap`: sidebar (256px) + content area (TWO columns)

## Understanding

Create the `(app)` route group layout — a two-column shell: Sidebar (256px) on the left,
scrollable content area on the right. A placeholder roadmap page makes the layout visible
at `/roadmap`.

**Critical override:** `15-web-build-specification.md` says "three-column (sidebar + content + detail panel)"
but `REQUEST.md` explicitly overrides this: "TWO columns, not three. NO DetailPanel."
The REQUEST.md + `web-responsive-layout` skill are authoritative. No DetailPanel is ever built.

**What AC-W2-03 covers vs later ACs:**
- AC-W2-03: Layout shell structure (flex container, sidebar slot with correct width, content slot)
- AC-W2-04: Sidebar nav content (logo, nav items, phase sections, user section)
- AC-W2-05: Sidebar collapse to 64px at 1024-1279px
- AC-W2-06: Mobile nav (<768px)
- AC-W2-07: Content area max-w-content verification

The Sidebar component for this AC is a **stub** — correct width/background, no nav items.
Nav items come in AC-W2-04.

**Layout pattern (from web-responsive-layout skill):**
```tsx
// app/(app)/layout.tsx
<div className="flex h-screen bg-bg">
  <Sidebar />                               // 256px fixed left
  <main className="flex-1 overflow-y-auto">
    <div className="max-w-content mx-auto px-6 lg:px-10 py-7">
      {children}
    </div>
  </main>
</div>
```

**Sidebar stub:**
```tsx
// components/layout/Sidebar.tsx
<aside className="w-sidebar h-full bg-bg-sidebar shrink-0 border-r border-border">
  {/* Navigation — built in AC-W2-04 */}
</aside>
```

The `max-w-content` (960px) centering is included in the layout file itself — AC-W2-07
verifies it works, but the implementation lives here.

## Constraints That Apply

- **CW01:** `w-sidebar`, `bg-bg-sidebar`, `border-border`, `max-w-content` — all tokens only, no raw values
- **TWO columns only** — no DetailPanel, no third column (architectural invariant)

- **Sidebar width:** `w-sidebar` (Tailwind token = 256px), NOT hardcoded `w-64`
