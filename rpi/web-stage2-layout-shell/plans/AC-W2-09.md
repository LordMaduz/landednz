# Implementation Plan: AC-W2-09 — Auth middleware: unauthenticated → /auth/signin?redirect={path}

## Approach
Create `apps/web/src/middleware.ts` using the Next.js Edge middleware API. The middleware checks for any cookie with the `sb-` prefix (standard Supabase auth cookie prefix) using `request.cookies.getAll()`. If no such cookie is found AND the path is protected, redirect to `/auth/signin?redirect={pathname}`. Protected paths: `/roadmap`, `/chat`, `/settings`. The `/auth/signin` path is intentionally excluded from the matcher to prevent redirect loops. No external packages required — this is a Stage 2 structural stub. Stage 4 will replace the one-line cookie check with `createServerClient().auth.getUser()` from @supabase/ssr.
