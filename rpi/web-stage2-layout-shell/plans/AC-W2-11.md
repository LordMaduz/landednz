# Implementation Plan: AC-W2-11 — Playwright E2E: all routes, correct layout at 1280 + 768

## Approach
Install @playwright/test and create a minimal E2E test suite in apps/web/e2e/layout.spec.ts. Two Playwright projects cover both required viewports: 1280px (desktop) and 768px (tablet). Tests inject sb-dev=1 cookie via page.context().addCookies() to bypass auth middleware for protected routes, then assert sidebar presence/absence based on route group.
