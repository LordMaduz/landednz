# Implementation Plan: AC-5-01

## Approach
Two-part implementation with zero architectural changes from spec. First, a Prisma migration adds the `embedding vector(1536)` column to `KnowledgeBaseChunk` via raw SQL (C16 — not expressible in Prisma schema syntax). Second, `scripts/generate-embeddings.ts` is built: fetches all 42 chunks where `embedding IS NULL`, calls OpenAI text-embedding-3-small API (1536 dims, exact spec match) for each chunk sequentially, and persists each embedding via `db.$queryRaw` UPDATE. The `openai` npm package is isolated in a new `shared/ai/embeddings.client.ts` (same isolation pattern as `claude.client.ts` for `@anthropic-ai/sdk`). The script must NOT create the ivfflat index (C05) — that runs manually after.

## File Changes
1. **Create** `apps/api/prisma/migrations/[timestamp]_add_embedding_column/migration.sql` — raw SQL: `ALTER TABLE "KnowledgeBaseChunk" ADD COLUMN IF NOT EXISTS embedding vector(1536);`
2. **Create** `apps/api/src/shared/ai/embeddings.client.ts` — wraps OpenAI SDK, exports `generateEmbedding(text: string): Promise<number[]>`. Only file that imports `openai`.
3. **Create** `apps/api/scripts/generate-embeddings.ts` — main script: fetch chunks, generate embeddings, write via `$queryRaw`, log progress, `db.$disconnect()`
4. **Modify** `apps/api/src/shared/config.ts` — add `openaiApiKey: requireEnv('OPENAI_API_KEY')`
5. **Modify** `apps/api/.env.local` — add `OPENAI_API_KEY=<key>`
6. **Modify** `apps/api/.env.example` — add `OPENAI_API_KEY=` with comment

## Implementation Order
1. `npm install openai` in `apps/api`
2. Create migration SQL file
3. `npx prisma migrate dev --name add_embedding_column`
4. Create `shared/ai/embeddings.client.ts` with `generateEmbedding()`
5. Add `openaiApiKey` to `config.ts` + `OPENAI_API_KEY` to `.env.local`
6. Create `scripts/generate-embeddings.ts`
7. Run: `npx ts-node scripts/generate-embeddings.ts`
8. Verify: `SELECT count(*) FROM "KnowledgeBaseChunk" WHERE embedding IS NULL` = 0

## Test Strategy
No unit tests — this is a one-shot operational script. AC verification:
- Script runs to completion with no errors
- `SELECT count(*) FROM "KnowledgeBaseChunk" WHERE embedding IS NULL` returns 0
- Spot-check: one chunk's embedding is a non-null 1536-element array
