Build `retrieveChunks()` in `apps/api/src/features/chat/rag/retrieval.ts`.
Write `apps/api/golden-examples/rag-retrieval.ts` first (TDD RED), then implement until Golden 1 passes.

The function performs a 6-step RAG pipeline:
1. Persona pre-filter in SQL (WHERE personaKey = input.personaKey OR personaKey IS NULL)
2. Generate query embedding via `generateEmbedding()` from `shared/ai/embeddings.client.ts`
3. Semantic search within filtered set (cosine `<=>`, LIMIT 10)
4. Re-rank: similarity (primary) → persona exactness (secondary) → contentVersion (tertiary)
5. Task context boost if taskContext provided
6. Return top 3–5 chunks
