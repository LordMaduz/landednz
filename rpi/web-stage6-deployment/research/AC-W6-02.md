# Research: AC-W6-02 — All env vars configured in Vercel

## Understanding

This AC requires configuring all necessary environment variables in the Vercel dashboard for the production web app deployment. The AC specifies 6 required environment variables:

**NEXT_PUBLIC_ variables (client-side accessible):**
- `NEXT_PUBLIC_API_URL` — Backend API endpoint URL
- `NEXT_PUBLIC_SUPABASE_URL` — Supabase project URL  
- `NEXT_PUBLIC_SUPABASE_ANON_KEY` — Supabase anonymous key
- `NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY` — Stripe publishable key for frontend

**Server-side only variables (NOT NEXT_PUBLIC_):**
- `STRIPE_PRICE_ID_MONTHLY` — Stripe price ID for monthly subscription
- `STRIPE_PRICE_ID_BIANNUAL` — Stripe price ID for 6-month subscription

The AC verification is "Inspect Vercel dashboard" and specifically calls out "No secrets in NEXT_PUBLIC_" as a security requirement.
