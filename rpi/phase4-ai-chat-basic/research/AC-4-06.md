# Research: AC-4-06 — OUT_OF_SCOPE_IMMIGRATION Level 1 guardrail

## Understanding

Add OUT_OF_SCOPE_IMMIGRATION detection to `runLevel1Guardrail()`. When a user
message matches any immigration enforcement/legal pattern (e.g. "my visa was
breached"), the guardrail fires and injects an augmentation that redirects the
user to `immigration.govt.nz/find-an-adviser`. Critically, the response must NOT
attempt to answer the immigration legal question — this is outside the settlement
advisor's scope.

The distinction is between legitimate settlement questions (visa conditions,
work rights, residency progress — all IN scope) versus immigration enforcement
and legal matters (visa breaches, deportation, overstays, appeals — OUT of scope).
The patterns target the latter category.

Same architecture as AC-4-04 and AC-4-05. Third `if` branch added after
PROMPT_INJECTION check.

## Functions / Routes / Tests

**level1.ts additions:**

```typescript
// OUT_OF_SCOPE_IMMIGRATION patterns — case-insensitive substring match
const OUT_OF_SCOPE_IMMIGRATION_PATTERNS: string[] = [
  "visa breach",
  "visa condition violated",
  "deportation",
  "overstayed",
  "visa appeal",
  "immigration lawyer",
  "visa cancelled",
  "unlawful stay",
];

// Redirect to immigration.govt.nz — model must NOT answer the question
const OUT_OF_SCOPE_IMMIGRATION_AUGMENTATION =
  `OUT OF SCOPE — REDIRECT ONLY:\n` +
  `This question involves immigration legal matters that are outside what I can ` +
  `help with. Acknowledge the concern with empathy, then direct the user to ` +
  `immigration.govt.nz/find-an-adviser where they can find a licensed immigration ` +
  `adviser. Do not attempt to answer the immigration legal question.`;
```

**runLevel1Guardrail() branch (after PROMPT_INJECTION check):**

```typescript
if (OUT_OF_SCOPE_IMMIGRATION_PATTERNS.some(pattern => lower.includes(pattern))) {
  return {
    triggered: true,
    flags: ['OUT_OF_SCOPE_IMMIGRATION'],
    augmentations: [OUT_OF_SCOPE_IMMIGRATION_AUGMENTATION],
  };
}
```

**Tests to add (level1.test.ts):**
- `"my visa was breached"` → OUT_OF_SCOPE_IMMIGRATION fires (exact AC input)
- `"I think I have overstayed"` → fires
- `"I need an immigration lawyer"` → fires
- Case-insensitive: `"VISA BREACH"` → fires
- In-scope guard: `"What are my visa conditions for working?"` → does NOT fire
- Normal message: `"How do I open a bank account?"` → does NOT fire
- Augmentation contains `immigration.govt.nz/find-an-adviser`
