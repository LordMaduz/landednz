# Implementation Plan: AC-W4-14 — Error handling

## Approach

Add proper error handling to 4 locations across the web app. (1) Create `error.tsx` as Next.js App Router error boundary for the roadmap route — catches network-level errors re-thrown from page.tsx and shows a retry card with a "Try again" button calling `reset()`. (2) Modify `page.tsx` to handle 401 (redirect to sign-in with `?redirect=/roadmap`) and re-throw network errors (no status code) so the error boundary catches them; 500s pass null to RoadmapView. (3) Modify `RoadmapView.tsx` to (a) show an inline error card when `initialData === null`, and (b) handle 401 in `handleTaskClick` catch by calling `router.push()`. (4) Modify `ChatPanel.tsx` to redirect on 401 in session init instead of setting `sessionError`. No new packages. All error UI uses existing design token classes (bg-error-light, border-error, text-error, rounded-button, etc.). No raw `error.message` strings exposed to users.

## Implementation Order

1. **Create `error.tsx`** — `'use client'` boundary. Props: `{ error: Error; reset: () => void }`. Renders a retry card: icon + "Something went wrong" heading + "Try again" button calling `reset()`. All classes from design tokens (bg-error-light, border-error, text-error, rounded-button, text-small, font-semibold).

2. **Modify `page.tsx`** — Add 401 check before the null return: `if ((err as {status?}).status === 401) redirect('/auth/signin?redirect=/roadmap')`. Re-throw errors with no `status` property (network failures) so error.tsx catches them. Keep null passthrough only for 4xx (other than 401) and 5xx.

3. **Modify `RoadmapView.tsx`** — (a) Add early return when `roadmapData === null && initialData === null`: render inline error card ("We couldn't load your roadmap" + "Refresh page" button). (b) In `handleTaskClick` catch: if status 401, call `router.push('/auth/signin?redirect=/roadmap')`; otherwise keep existing console.error (detail stays undefined → skeleton shown, but no crash). Use `useRouter` from `next/navigation`.

4. **Modify `ChatPanel.tsx`** — Import `useRouter` from `next/navigation`. In session init catch: if `status === 401`, call `router.push('/auth/signin?redirect=/roadmap')` instead of setting `sessionError`. Keep existing 403 premium message and generic fallback. In `onError` callback: if errorMessage includes '401' or 'Unauthorized', call `router.push('/auth/signin?redirect=/roadmap')` instead of adding system message.

5. **TypeScript check** — `npx tsc --noEmit` from `apps/web` → 0 errors.
