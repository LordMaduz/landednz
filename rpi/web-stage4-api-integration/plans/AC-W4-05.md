# Implementation Plan: AC-W4-05
# Roadmap fetches from GET /roadmap, hero card correct counts, topThree correct

## Approach

`page.tsx` becomes an async server component that fetches `GET /roadmap` using the Supabase
session token. On 404, it redirects to `/onboarding` (fixing the first-time-user flow). On
success, it passes `RoadmapApiResponse` to `RoadmapView` as `initialData` prop. A new
pure-function module `roadmap-mapper.ts` handles all API→web type mapping (isolated for
AC-W4-06 unit testing). `RoadmapView` removes mock imports, derives all data from `initialData`,
and remains a client component (still uses `useState`).

## Mapping Logic

**`deriveCardState(task: RoadmapApiTask): TaskCardState`:**
- `status === 'COMPLETE'` → `'complete'`
- `isBlocked === true` (and not COMPLETE) → `'blocked'`
- `taskType === 'PREMIUM'` (and not COMPLETE, not blocked) → `'premium_locked'`
- `status === 'IN_PROGRESS'` → `'in_progress'`
- `status === 'NOT_STARTED'` → `'not_started'`

**`mapApiTaskToListItem(task: RoadmapApiTask): TaskListItem`:**
- `name` → `taskName`
- `taskType === 'PREMIUM'` → `isPremium: true`
- `blockingTaskNames[0]` → `blockedBy: { taskId: '', taskName: blockingTaskNames[0] }` (only if non-empty)
- `difficulty`: omitted (not in API — field is optional in TaskListItem)
- `completedAt`: omitted (not in API)

**`PHASE_META` hardcoded constants:**
```
1: { name: 'Before you start working', timeline: 'Before you arrive', isPremium: false }
2: { name: 'First 2 weeks', timeline: 'Weeks 1–2', isPremium: false }
3: { name: 'Settling in', timeline: 'Months 1–3', isPremium: true }
```

**`RoadmapView.tsx` data derivation:**
- `phases` = `initialData ? mapApiPhasesToWeb(initialData.phases) : []`
- `allTasksFlat` = flatten all tasks from `phases` (all `TaskListItem[]` across all phases)
- `priorityTasks` = `initialData ? initialData.topThree.map(mapApiTaskToListItem) : []`
- `HeroCard tasks={allTasksFlat}` — full task list for correct complete/in_progress/remaining counts
- `initialData === null` → empty arrays → empty roadmap (AC-W4-14 wires error UI)
