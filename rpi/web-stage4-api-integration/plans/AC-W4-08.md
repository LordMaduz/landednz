# Implementation Plan: AC-W4-08
# Mark as done: optimistic update + rollback on failure
# Constitutional Validator: PASS

---

## Approach

Wire the two placeholder action buttons ("Mark as done" / "I've already done this") in
`TaskDetail.tsx` to a new `onComplete: () => Promise<void>` prop. `RoadmapView` holds
local `useState<RoadmapApiResponse | null>` (seeded from the SSR `initialData` prop) and
owns a `handleComplete(taskId)` function that:
1. Immediately mutates local state to mark the task as COMPLETE (optimistic),
2. Calls `POST /roadmap/tasks/:taskId/complete`,
3. Re-fetches `GET /roadmap` on success → updates state → navigates back to list,
4. Rolls back local state and fires a toast error on failure.

Install `sonner` for toast — the de-facto standard for Next.js App Router.
No Zustand store introduced (that belongs to AC-W4-15).

```typescript
export async function completeTask(taskId: string, token: string): Promise<void> {
  const res = await fetch(`${API_URL}/roadmap/tasks/${taskId}/complete`, {
    method: 'POST',
    headers: { Authorization: `Bearer ${token}` },
  })
  if (!res.ok) throw new Error(`Complete task failed: ${res.status}`)
}
```

**4b** — Add `handleComplete`:
```typescript
const handleComplete = async (taskId: string) => {
  if (!roadmapData) return
  const previousData = roadmapData

  // Optimistic: mark task COMPLETE in local state immediately
  const optimisticData: RoadmapApiResponse = {
    ...roadmapData,
    phases: roadmapData.phases.map(phase => ({
      ...phase,
      tasks: phase.tasks.map(t =>
        t.taskId === taskId ? { ...t, status: 'COMPLETE' as const } : t
      ),
    })),
    topThree: roadmapData.topThree.map(t =>
      t.taskId === taskId ? { ...t, status: 'COMPLETE' as const } : t
    ),
  }
  setRoadmapData(optimisticData)

  try {
    await completeTask(taskId, token)
    const freshData = await getRoadmap(token)
    setRoadmapData(freshData)
    setSelectedTask(null)  // navigate back to list on success
  } catch {
    setRoadmapData(previousData)  // rollback
    toast.error('Something went wrong. Your progress was not saved.')
  }
}
```

   - **Expected**: success path works again
