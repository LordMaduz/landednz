# Implementation Plan: AC-W4-04 — Onboarding submits to POST /onboarding/profile, profile persisted, GET /roadmap returns personalised roadmap

## Approach

Create `src/lib/api.ts` as the project-wide typed API client — flat exported functions, no
class. Add `submitOnboardingProfile()` as the first function. Modify `RoadmapReveal.tsx` to
call this function when the user clicks "See my roadmap →", converting the human-readable
arrival string to an ISO date approximation. Show button loading state during the call;
navigate to `/roadmap` on 201 or 409 (profile exists); show inline error on other failures.
Auth token comes from `supabase.auth.getSession()` (browser client, CW06 compliant).

## File Changes

- **Create** `apps/web/src/lib/api.ts` — typed API client; `submitOnboardingProfile(payload, token)` only for this AC
- **Modify** `apps/web/src/components/onboarding/RoadmapReveal.tsx` — add `arrivalToISODate()` helper, `submitting`/`submitError` state, `handleSeeRoadmap` async function, wire button

## Implementation Order

1. **Create `apps/web/src/lib/api.ts`:**
   - Import `VisaType`, `City`, `FamilySituation`, `Occupation` from `@landednz/types`
   - Define `SubmitProfilePayload` interface (web-specific, lives in api.ts)
   - Implement `submitOnboardingProfile(payload: SubmitProfilePayload, token: string): Promise<void>`
   - Fetch `POST ${process.env.NEXT_PUBLIC_API_URL}/onboarding/profile` with JSON body + Bearer token
   - Throw on non-ok AND non-409 (`res.status !== 409`)

2. **Modify `RoadmapReveal.tsx`:**
   - Add imports: `createClient` from `@/lib/supabase/client`, `submitOnboardingProfile` from `@/lib/api`
   - Add file-level `arrivalToISODate(arrival: string): string` helper:
     - "I haven't arrived yet" → today + 30 days
     - "I arrived in the last 2 weeks" → today − 7 days
     - "I arrived 2–8 weeks ago" → today − 35 days
     - fallback (incl. "More than 2 months ago") → today − 90 days
   - Add `const [submitting, setSubmitting] = useState(false)` and `const [submitError, setSubmitError] = useState('')`
   - Add `handleSeeRoadmap` async function:
     1. `setSubmitting(true)`, `setSubmitError('')`
     2. Get session via `supabase.auth.getSession()` → `session.access_token`
     3. If no session: `setSubmitting(false)`, `router.push('/auth/signin')`, return
     4. Call `submitOnboardingProfile({ visaType, city, familySituation, occupation, arrivalDate: arrivalToISODate(answers.arrivalDate ?? '') }, token)`
     5. `router.push('/roadmap')`
     6. `catch`: `setSubmitting(false)`, `setSubmitError('Something went wrong. Please try again.')`
   - Replace `onClick={() => router.push('/roadmap')}` with `onClick={handleSeeRoadmap}`
   - Add `disabled={submitting}` to button
   - Show spinner inside button when `submitting` (inline SVG with `animate-spin`)
   - Show `{submitError && <p className="text-caption text-error mt-3">{submitError}</p>}` below button

3. Run `npx tsc --noEmit` in `apps/web`
