# Implementation Plan: AC-W4-02 — Auth middleware: unauthenticated → signin, after auth → original path

## Approach

Upgrade `middleware.ts` from the naive Stage 2 `sb-*` cookie prefix check to a real Supabase
session validation using `createServerClient().auth.getUser()` from `@supabase/ssr`. The
middleware runs in Edge runtime so it must use `request.cookies` (not `next/headers`). It must
return `supabaseResponse` (not a plain `NextResponse.next()`) so token refresh cookies propagate
to the browser.

Fix the broken "return to original path" flow by updating `AuthCard.tsx` to read the `?redirect=`
param from the current signin URL and pass it into the OAuth `redirectTo`. The callback route
already reads and acts on this param — no changes needed there.

## File Changes

- **Modify** `apps/web/src/middleware.ts` — replace naive `sb-*` cookie check with
  `createServerClient().auth.getUser()` using Edge-safe cookie config
- **Modify** `apps/web/src/components/auth/AuthCard.tsx` — in `handleGoogleClick`, read
  `?redirect=` from `window.location.search`, encode and append to `redirectTo`

No new files. No Storybook story changes (no UI change).

## Implementation Order

1. **Modify `middleware.ts`:**
   - Import `createServerClient` from `@supabase/ssr`
   - Make function `async`
   - Initialise `let supabaseResponse = NextResponse.next({ request })`
   - Construct Supabase client with Edge-safe cookie handlers:
     - `getAll()` reads from `request.cookies.getAll()`
     - `setAll()` writes to both `request.cookies` AND `supabaseResponse.cookies`
     (rebuilds `supabaseResponse` via `NextResponse.next({ request })` in between)
   - Call `const { data: { user } } = await supabase.auth.getUser()`
   - If `isProtected && !user`: redirect to `/auth/signin?redirect={pathname}`
   - Otherwise: return `supabaseResponse` (NOT `NextResponse.next()`)

2. **Modify `AuthCard.tsx` `handleGoogleClick`:**
   - Read `const params = new URLSearchParams(window.location.search)`
   - `const redirect = params.get('redirect') ?? '/roadmap'`
   - Set `redirectTo: \`${window.location.origin}/auth/callback?redirect=${encodeURIComponent(redirect)}\``
