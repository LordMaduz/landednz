# Implementation Plan: AC-W4-15 — Zustand stores: roadmapStore + chatStore, persist across nav, reset on sign out

## Approach

Create two in-memory Zustand stores to hold cross-navigation state within a browser session (CW06 compliant). (1) Create `roadmapStore.ts` with roadmapData, filter, selectedTask, gateState plus actions. (2) Extend `chatStore.ts` with messages, isStreaming, streamingText plus actions. (3) Migrate `RoadmapView.tsx` from component useState to useRoadmapStore — hydrate store from RSC initialData on mount if store is null. (4) Migrate `ChatPanel.tsx` from component useState to chatStore for messages/streaming state — keep sessionId/sessionError/input as local state. (5) Add sign-out reset: `SettingsView.tsx` calls reset() on both stores before router navigation. "Persist across nav" means state survives React Router navigation within the same browser session (normal Zustand behavior) — stores are in-memory only, reset on page refresh/close. "Reset on sign out" prevents data leaking to next user session. No localStorage usage — stores follow CW06 in-memory pattern.

## Implementation Order

1. **Create `roadmapStore.ts`** — Zustand store with roadmapData, filter, selectedTask, gateState state + setters + updateSelectedTask helper + reset(). Import existing types: RoadmapApiResponse, FilterValue, TaskListItem, PremiumGateState from @/types/web. Store is in-memory only (normal Zustand behavior, no persistence middleware).

2. **Extend `chatStore.ts`** — Add messages (Message[]), isStreaming (boolean), streamingText (string), sessionId (string | null) to existing interface. Add setters: setMessages, addMessage, setStreaming, setStreamingText, setSessionId. Update close() to call reset() which clears all new fields. Update reset() to clear everything including isOpen. Store remains in-memory only.

3. **Modify `RoadmapView.tsx`** — Replace useState destructuring with useRoadmapStore. Add useEffect to hydrate store from initialData on mount (only if store.roadmapData is null). Update handleComplete + handleTaskClick to use store setters instead of local setters. Remove local state declarations.

4. **Modify `ChatPanel.tsx`** — Replace useState for messages, isStreaming, streamingText with useChatStore equivalents. Update all message array operations (push, concat) to use store.addMessage/setMessages. Update streaming operations to use store setters. Keep streamingTextRef as local ref for closure safety. Keep sessionId, sessionError, input as component state.

5. **Modify `SettingsView.tsx`** — Import useRoadmapStore, useChatStore. In handleSignOut: call useRoadmapStore.getState().reset() + useChatStore.getState().reset() before supabase.auth.signOut() and router.push('/').

6. **TypeScript check** — `npx tsc --noEmit` from `apps/web` → 0 errors.
