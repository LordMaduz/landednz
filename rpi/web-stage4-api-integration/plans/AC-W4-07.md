# Implementation Plan: AC-W4-07

## Approach

Wire up real `GET /roadmap/tasks/:taskId` API calls when a user clicks a task row on the roadmap.
`TaskDetail.tsx` and `TaskDetailData` already exist from Stage 3. The work is: (1) add
`getTaskDetail()` to `api.ts` with a `TaskDetailApiResponse` type mirroring the backend exactly,
(2) add `mapApiTaskDetail()` mapper in `roadmap-mapper.ts` converting API fields to `TaskDetailData`
shape, (3) update `RoadmapView.tsx` to fetch on click and update the selected task with real detail,
(4) pass `token` from `page.tsx` (server component, has session) to `RoadmapView` (client component).

`TaskDetailData.whyNow` is made optional — the API doesn't have a separate `whyNow` field, and the
amber callout already shows `task.consequenceLine` (which IS the "why now" content). The "Why now?"
detail section is wrapped in a conditional so it doesn't show an empty paragraph.

## Implementation Order

1. `api.ts` — add `TaskDetailApiResponse` type and `getTaskDetail(taskId, token)`:
   ```typescript
   export async function getTaskDetail(taskId: string, token: string): Promise<TaskDetailApiResponse> {
     const res = await fetch(`${API_URL}/roadmap/tasks/${taskId}`, {
       headers: { Authorization: `Bearer ${token}` },
       cache: 'no-store',
     })
     if (!res.ok) {
       throw Object.assign(new Error('Task detail fetch failed'), { status: res.status })
     }
     return res.json()
   }
   ```

2. `roadmap-mapper.ts` — add `mapApiTaskDetail()`:
   ```typescript
   export function mapApiTaskDetail(response: TaskDetailApiResponse): TaskDetailData {
     const tips = [...response.watchOuts, ...response.commonMistakes]
     const source = parseSourceFromUrl(response.governmentSourceUrl)
     return {
       steps: response.steps.map(s => ({ text: s })),
       documents: response.documentsRequired.map(name => ({ name, required: true })),
       source: source ?? undefined,
       tips: tips.length > 0 ? tips : undefined,
     }
   }

   function parseSourceFromUrl(url: string): TaskDetailSource | null {
     try {
       const { hostname } = new URL(url)
       return { agency: hostname.replace('www.', ''), page: '', url }
     } catch {
       return null
     }
   }
   ```

3. `types/web.ts` — make `whyNow` optional:
   ```typescript
   export interface TaskDetailData {
     whyNow?: string;   // optional — API doesn't provide this separately
     steps?: TaskDetailStep[];
     ...
   }
   ```

4. `TaskDetail.tsx` — wrap "Why now?" section conditionally:
   ```tsx
   {detail.whyNow && (
     <div className="mb-6">
       <h3 className="text-h3 text-text-primary mb-2">Why now?</h3>
       <p className="text-body text-text-secondary">{detail.whyNow}</p>
     </div>
   )}
   ```

5. `RoadmapView.tsx` — add `token` prop + fetch logic:
   ```typescript
   interface RoadmapViewProps {
     initialData: RoadmapApiResponse | null
     token: string
   }
   // ...
   const handleTaskClick = (task: TaskListItem) => {
     setSelectedTask(task)
     getTaskDetail(task.taskId, token)
       .then(res => setSelectedTask(prev => prev ? { ...prev, detail: mapApiTaskDetail(res) } : prev))
       .catch(() => { /* AC-W4-14 adds error UI — for now, detail stays undefined */ })
   }
   ```

6. `page.tsx` — pass token:
   ```tsx
   return <RoadmapView initialData={data} token={session.access_token} />
   ```
   (Also pass `token={session.access_token}` in the error fallback branch.)

7. Run `npx tsc --noEmit` from `apps/web/` — zero errors
8. Run `npm run test` from `apps/web/` — all passing
9. Manual verification with API running
