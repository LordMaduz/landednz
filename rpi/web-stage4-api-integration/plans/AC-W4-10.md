# Implementation Plan: AC-W4-10 — Chat entry-point-aware

## Approach

Create a minimal Zustand `chatStore` (`isOpen + entryPoint + taskId`) as the cross-component bridge between `TaskDetail` (deep in the roadmap page) and `ChatWidget` (in the server-rendered layout). `ChatWidget` migrates from local `useState` to this store. The FAB calls `open('ROADMAP')`. `TaskDetail` receives an `onOpenChat` callback from `RoadmapView` that calls `open('TASK_CARD', task.taskId)`. `ChatPanel` forwards `taskId` to `createChatSession()` — the backend validates that `TASK_CARD` always has `taskContext` and looks up the task name itself. The store interface is designed to be extended in AC-W4-15.

## Implementation Order

1. **Create `chatStore.ts`** — Zustand store with `isOpen`, `entryPoint` (default `'ROADMAP'`), `taskId`, `open(entryPoint, taskId?)`, `close()`.

2. **Modify `ChatPanel.tsx`** — Add `taskId?: string` prop. In `initSession()`, pass it as third arg to `createChatSession(entryContext ?? 'ROADMAP', token, taskId)`.

3. **Modify `ChatWidget.tsx`** — Replace `const [chatOpen, setChatOpen] = useState(false)` with `useChatStore`. Read `isOpen`, `open`, `close` from store. FAB `onClick` calls `open('ROADMAP')`. Pass `entryContext` and `taskId` from store into `ChatPanel`.

4. **Modify `TaskDetail.tsx`** — Add `onOpenChat?: () => void` to `TaskDetailProps`. Wire the "Ask a question" button `onClick={onOpenChat}`.

5. **Modify `RoadmapView.tsx`** — Import `useChatStore`. In the `selectedTask` render branch, pass `onOpenChat={() => useChatStore.getState().open('TASK_CARD', selectedTask.taskId)}` to `TaskDetail`.

6. **TypeScript check** — `npx tsc --noEmit` from `apps/web` → 0 errors.
