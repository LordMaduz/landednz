# Research: AC-W4-04 — Onboarding submits to POST /onboarding/profile, profile persisted, GET /roadmap returns personalised roadmap

## Understanding

The `OnboardingFlow` collects 5 answers and passes them to `RoadmapReveal`. The reveal plays
an animation then shows a "See my roadmap →" button. Currently that button just calls
`router.push('/roadmap')` — no API call is made.

AC-W4-04 must:
1. On "See my roadmap →" click, call `POST /onboarding/profile` with the collected answers
2. Navigate to `/roadmap` on success (201) OR if profile already exists (409)
3. Show button loading state during the API call
4. Show inline error if the API call fails for any other reason

**Critical mismatch to resolve:** The `OnboardingFlow` stores arrival as a human-readable
string ("I haven't arrived yet", "I arrived in the last 2 weeks", etc.), but the API
requires a valid ISO date string (e.g. "2024-03-15"). A mapping function is needed:

| UI value | ISO date approximation |
|---|---|
| "I haven't arrived yet" | today + 30 days |
| "I arrived in the last 2 weeks" | today − 7 days |
| "I arrived 2–8 weeks ago" | today − 35 days |
| "More than 2 months ago" | today − 90 days |

**Auth:** `RoadmapReveal` is a `'use client'` component. Use `createClient()` (browser) to
get the session access token for the `Authorization: Bearer <token>` header.

**Profile already exists (409):** Not an error — user may have refreshed. Treat 409 as
success and navigate to `/roadmap`.

## Functions / Routes / Tests

### `src/lib/api.ts` (new)

```typescript
const API_URL = process.env.NEXT_PUBLIC_API_URL

export interface SubmitProfilePayload {
  visaType: VisaType
  city: City
  familySituation: FamilySituation
  occupation: Occupation
  arrivalDate: string  // ISO date
}

export async function submitOnboardingProfile(
  payload: SubmitProfilePayload,
  token: string,
): Promise<void> {
  const res = await fetch(`${API_URL}/onboarding/profile`, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      Authorization: `Bearer ${token}`,
    },
    body: JSON.stringify(payload),
  })
  if (!res.ok && res.status !== 409) {
    throw new Error(`Profile submission failed: ${res.status}`)
  }
  // 409 = profile already exists, fine to proceed
}
```

### `RoadmapReveal.tsx` changes

**Arrival mapping helper** (file-level, before the component):
```typescript
function arrivalToISODate(arrival: string): string {
  const today = new Date()
  const d = (days: number) =>
    new Date(today.getTime() + days * 86_400_000).toISOString().split('T')[0]
  if (arrival === "I haven't arrived yet") return d(30)
  if (arrival === 'I arrived in the last 2 weeks') return d(-7)
  if (arrival === 'I arrived 2–8 weeks ago') return d(-35)
  return d(-90) // "More than 2 months ago" + fallback
}
```
