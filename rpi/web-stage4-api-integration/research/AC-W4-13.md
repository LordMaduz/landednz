# Research: AC-W4-13 — All loading states use skeleton components

## Understanding

Three distinct loading moments need skeleton treatment. The `Skeleton` component from Stage 1 already exists with `text-line`, `card`, and `circle` variants + `skeleton-pulse` animation in globals.css.

### Loading moment 1 — Roadmap initial page load

`RoadmapPage` is a server component that fetches `GET /roadmap` before rendering. Next.js App Router will auto-show `apps/web/src/app/(app)/roadmap/loading.tsx` during this fetch. This file doesn't exist yet — creating it will give an instant skeleton during the server-side wait. The skeleton should approximate the real roadmap layout: teal hero card, 3 priority task rows, filter tabs, phase section headers.

**Trigger:** Network-throttled or slow API response on `/roadmap` page load.

### Loading moment 2 — Task detail section loading

When a user clicks a task:
1. `handleTaskClick()` calls `setSelectedTask(task)` immediately → `TaskDetail` renders
2. `getTaskDetail()` is called async → detail populates when it completes

Currently `TaskDetail` shows `"Detailed guidance coming soon."` text when `detail === undefined` (loading). The AC requires skeleton components here instead.

**Type contract:** `task.detail?: TaskDetailData` — `undefined` = not yet fetched, `TaskDetailData` = loaded. The header, consequence callout, and action buttons always render from `task` object (never need skeletons). Only the `detail` section (steps, documents, source, tips) needs the skeleton.

**Trigger:** Click any task row — detail skeleton visible for ~200-500ms before API responds.

### Loading moment 3 — Chat session initialising

On `ChatPanel` mount, `createChatSession()` is called. While `sessionId === null && sessionError === null`, the messages area is empty — no visual feedback. The AC requires a loading skeleton here.

**Condition to show:** `sessionId === null && sessionError === null` (the init window)
**Content:** 2 stacked skeleton message bubbles (simulating loading AI + user area)

**Trigger:** Open chat FAB or "Ask a question" — skeleton visible for ~300-800ms.

## Functions / Routes / Tests

**`loading.tsx`:**
```tsx
import { Skeleton } from '@/components/ui/Skeleton'

export default function RoadmapLoading() {
  return (
    <div>
      {/* Hero card */}
      <Skeleton variant="card" height="h-32" className="mb-6" />
      {/* Section label */}
      <Skeleton variant="text-line" width="w-40" className="mb-4 h-5" />
      {/* 3 priority task row skeletons */}
      {[1,2,3].map(i => <TaskRowSkeleton key={i} />)}
      {/* Filter tabs */}
      <Skeleton variant="text-line" width="w-64" className="my-6 h-9 rounded-full" />
      {/* Phase header + 2 task rows */}
      <Skeleton variant="text-line" width="w-32" className="mb-3 h-5" />
      {[1,2].map(i => <TaskRowSkeleton key={i} />)}
    </div>
  )
}

function TaskRowSkeleton() {
  return (
    <div className="flex items-center gap-3 px-3 py-3 border border-border rounded-card mb-2">
      <Skeleton variant="circle" className="w-6 h-6 flex-shrink-0" />
      <div className="flex-1 space-y-2">
        <Skeleton variant="text-line" width="w-1/2" />
        <Skeleton variant="text-line" width="w-3/4" />
      </div>
      <Skeleton variant="text-line" width="w-16" className="h-5" />
    </div>
  )
}
```

**`TaskDetail.tsx` change:**
```tsx
// Before (line ~166):
{detail ? (
  <>...rich content...</>
) : (
  <div className="mb-8 text-small text-text-tertiary">Detailed guidance coming soon.</div>
)}

// After:
{detail === undefined ? (
  <TaskDetailLoadingSkeleton />
) : detail ? (
  <>...rich content...</>
) : (
  <div className="mb-8 text-small text-text-tertiary">Detailed guidance coming soon.</div>
)}
```

`TaskDetailLoadingSkeleton` is a local function in the file showing ~4 skeleton blocks mimicking the steps/documents/source sections.

**`ChatPanel.tsx` change:**
```tsx
// In the messages area, when sessionId === null && !sessionError:
{!sessionError && sessionId === null ? (
  <div className="p-4 space-y-4">
    <Skeleton variant="text-line" width="w-3/4" className="h-12 rounded-xl" />
    <Skeleton variant="text-line" width="w-1/2" className="h-8 rounded-xl ml-auto" />
  </div>
) : sessionError ? (
  <error state>
) : (
  <messages>
)}
```
