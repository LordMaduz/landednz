# Implementation Plan: AC-W1-08

## Approach

Build a `ProgressBar` primitive component with deterministic (0-100% value with 0.4s fill transition) and indeterminate (opacity pulse) modes. Follow the established component API pattern from Button/Card/Badge with variant-based styling using `cn()` utility. Add a new `duration-fill: '400ms'` token to `tailwind.config.ts` for CW01 compliance since 400ms is not in Tailwind's default duration scale. Create comprehensive Storybook stories including an interactive range control for the value prop. Implement full WCAG accessibility with proper `role="progressbar"` and ARIA attributes.

## Implementation Order

1. **Update tailwind.config.ts** — Add `duration-fill` custom token to support 0.4s transition spec
2. **Update globals.css** — Add `progress-pulse` keyframes for indeterminate mode (0.4→0.7→0.4 opacity, 1.5s)
3. **Create ProgressBar.tsx** — Component with props interface, size/mode variants, accessibility attributes
4. **Create ProgressBar.stories.tsx** — 6 stories: Default, Empty, Full, Indeterminate, Sizes, Interactive
5. **Update index.ts** — Add barrel export for ProgressBar component
6. **Manual verification** — Test all states in Storybook, verify accessibility and reduced motion compliance
