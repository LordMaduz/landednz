# Implementation Plan: AC-W1-09 — Skeleton component

**Constitutional validator:** PASS (0 violations, all 16 constraints checked)

## Approach

Add a `Skeleton` UI primitive to `apps/web/src/components/ui/`. Three variants
(`text-line`, `card`, `circle`) control shape and radius defaults. All variants
use `bg-blocked-light` as the base colour and apply a `.skeleton-pulse` CSS class
that pulses opacity 0.4→0.7→0.4 over 1.5s. The pulse class is gated behind
`@media (prefers-reduced-motion: no-preference)` so it is completely silent when
the user has reduced motion enabled. The existing `@keyframes progress-pulse` in
`globals.css` is reused — no duplicate keyframe definitions. No new Tailwind tokens
are required; `bg-blocked-light`, `rounded-card`, and `rounded-full` already exist.

## Implementation Order

1. **globals.css** — add `.skeleton-pulse` class (reuses existing `progress-pulse` keyframe):
   ```css
   @media (prefers-reduced-motion: no-preference) {
     .skeleton-pulse {
       animation: progress-pulse 1.5s ease-in-out infinite;
     }
   }
   ```

2. **Skeleton.tsx** — component + exported types:
   ```typescript
   import React from 'react'
   import { cn } from '@/lib/utils/cn'

   export type SkeletonVariant = 'text-line' | 'card' | 'circle'

   export interface SkeletonProps {
     variant: SkeletonVariant
     width?: string      // Tailwind width class override e.g. 'w-32'
     height?: string     // Tailwind height class override e.g. 'h-8'
     className?: string
   }

   const variantStyles: Record<SkeletonVariant, string> = {
     'text-line': 'w-full h-4 rounded-full',
     'card':      'w-full h-32 rounded-card',
     'circle':    'w-10 h-10 rounded-full',
   } as const

   export function Skeleton({ variant, width, height, className }: SkeletonProps) {
     return (
       <div
         role="status"
         aria-label="Loading"
         aria-busy="true"
         className={cn(
           'bg-blocked-light skeleton-pulse',
           variantStyles[variant],
           width,
           height,
           className,
         )}
       />
     )
   }
   ```

3. **Skeleton.stories.tsx** — 6 stories:
   - `TextLine` — single text-line, full width
   - `Card` — card variant
   - `Circle` — circle variant
   - `AllVariants` — gallery of all three in a column
   - `ReducedMotion` — all three variants with `parameters: { chromatic: { prefersReducedMotion: 'reduce' } }` + label overlay "Pulse disabled with prefers-reduced-motion"
   - `ComposedExample` — realistic task card placeholder (circle avatar + 3 text-lines of varying widths)

4. **index.ts** — append:
   ```typescript
   export { Skeleton } from './Skeleton'
   export type { SkeletonProps, SkeletonVariant } from './Skeleton'
   ```
