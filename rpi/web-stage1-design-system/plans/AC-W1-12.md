# Implementation Plan: AC-W1-12

## Approach
Build a `Tooltip` UI primitive using a wrapper `div` as the positioning context and event surface. Visibility is managed with `useState`; hover (`onMouseEnter/onMouseLeave`) and focus (`onFocus/onBlur`) on the wrapper trigger show/hide. Click-outside and Escape key dismiss via `useEffect` listeners. The tooltip box is absolutely positioned relative to the wrapper using four pre-defined position class sets. A `w-2 h-2 rotate-45` rotated square renders the directional arrow. `React.cloneElement` injects `aria-describedby` onto the trigger child for accessibility. No animations used — conditional rendering only, so CW03 is trivially satisfied.

## File Changes
- **Create** `apps/web/src/components/ui/Tooltip.tsx` — component with 4-position layout, arrow, hover/focus/click-outside/Escape dismiss logic, and ARIA support
- **Create** `apps/web/src/components/ui/Tooltip.stories.tsx` — 7 stories: Top, Bottom, Left, Right, AllPositions, WithControls, LongContent
- **Modify** `apps/web/src/components/ui/index.ts` — add barrel exports for Tooltip and TooltipPosition

## Implementation Order
1. Create `Tooltip.tsx` with TypeScript interfaces (`TooltipPosition`, `TooltipProps`)
2. Implement position class maps for tooltip box and arrow placement
3. Implement wrapper with hover/focus event handlers and `useState` visibility
4. Implement `useEffect` for click-outside (`mousedown`) and Escape (`keydown`) dismiss
5. Render tooltip box with `role="tooltip"`, `pointer-events-none`, arrow div
6. Use `React.cloneElement` to inject `aria-describedby` on the trigger child
7. Create `Tooltip.stories.tsx` with 7 stories (all positions + interactive control)
8. Update barrel exports in `ui/index.ts`
9. Run `npx tsc --noEmit` and Storybook smoke test to verify

- `AllPositions` grid shows all 4 simultaneously
- `WithControls` story responds to Storybook controls (position + content)
