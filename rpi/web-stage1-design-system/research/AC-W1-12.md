# Research: AC-W1-12 — Tooltip component

## Understanding

Build a `Tooltip` UI primitive that wraps any trigger element and shows contextual
content on hover and focus. The tooltip supports 4 positions (top/bottom/left/right),
has a directional arrow pointing at the trigger, and dismisses when the user clicks
outside or presses Escape. An interactive Storybook story lets the reviewer switch
positions via controls.

This is a dark-background tooltip (standard UI pattern) — dark bg, white text.
Based on the `shadow-dropdown` shadow token which is the right weight for floating
overlays of this type.

## Functions / Routes / Tests

**Component API:**
```typescript
export type TooltipPosition = 'top' | 'bottom' | 'left' | 'right'

export interface TooltipProps {
  content: React.ReactNode      // Tooltip text/content
  position?: TooltipPosition    // Default: 'top'
  children: React.ReactElement  // Trigger element — ReactElement to allow cloneElement
  className?: string            // Applied to the tooltip box
}
```

**Visual design (all tokens exist):**

| Property | Token | Value |
|----------|-------|-------|
| Background | `bg-text-primary` | #1A1A2E (dark) |

| Position | Tooltip placement | Arrow placement |

**Behavior implementation:**
- Wrapper `div` with `relative inline-block` — provides positioning context
- `onMouseEnter/onMouseLeave` — hover trigger
- `onFocus/onBlur` — keyboard focus trigger (React bubbles focus from children)
- `useEffect` with `mousedown` on `document` — click-outside dismiss
- `useEffect` with `keydown` on `document` (Escape key) — keyboard dismiss
- `React.cloneElement(children, { 'aria-describedby': tooltipId })` — injects accessibility link
- Tooltip element: `role="tooltip"`, `id={tooltipId}`, `pointer-events-none`
- No animation for Stage 1 — conditional rendering only (CW03: no transitions to worry about)

**Storybook stories:**
- `Top` — default position with a button trigger
- `Bottom` — bottom position
- `Left` — left position
- `Right` — right position
- `AllPositions` — 2×2 grid showing all 4 positions simultaneously
- `WithControls` — interactive Storybook args control for position and content
- `LongContent` — tooltip with a multi-word label to show wrapping behaviour

## Ambiguities / Questions

**Arrow z-index:** The arrow `div` is a sibling inside the tooltip box and positioned
absolutely. The rotated square may partially clip against the trigger. Standard solution:
use `overflow-visible` on the tooltip container. This is the default for `div` — no extra
class needed.

**Whitespace:** Defaulting to `whitespace-nowrap` for single-line tooltip text (most common
use case). Consumer can override with `className` prop if multi-line content is needed.

**`'use client'` directive:** Tooltip uses `useState`/`useEffect`. Following the existing
component pattern in this codebase (Input.tsx also uses hooks without `'use client'`).
Consistent with all other UI primitives in Stage 1.
