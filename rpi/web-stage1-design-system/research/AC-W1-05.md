# Research: AC-W1-05 — Button component

## Understanding

AC-W1-05 creates the Button UI primitive — the most-used interactive element across the
entire product. It's used for primary CTAs (mark as done, build my plan), secondary actions
(save progress), outline controls (close, cancel), text links (delete account), and
destructive confirmations.

The component ships with a Storybook story covering all 60 state combinations
(5 variants × 3 sizes × 4 states). This is the first component AC, which raises
a question about Storybook installation (see Ambiguities).

## Functions / Components / States

**5 variants** (from design system skill):

| Variant | Background | Text | Hover |
|---------|------------|------|-------|
| `primary` | `bg-primary` | `text-text-inverse` | `hover:bg-primary-hover` |
| `secondary` | `bg-secondary` | `text-text-primary` | `hover:bg-secondary-hover` |
| `outline` | transparent | `text-primary` | `hover:bg-primary-subtle` |
| `text` | transparent | `text-primary` | `hover:bg-primary-subtle` |
| `destructive` | `bg-error` | `text-text-inverse` | `hover:bg-error-hover` |

**3 sizes** (padding-based, no explicit height token needed):

| Size | Classes | Target height |
|------|---------|--------------|
| `sm` | `px-3 py-2 text-secondary` | ~36px |
| `md` | `px-4 py-3 text-body` | ~44px |
| `lg` | `px-6 py-4 text-body` | ~52px |

**4 states:**
- `default` — base appearance
- `hover` — hover colour change (interactive)
- `disabled` — `opacity-50 cursor-not-allowed`, `disabled` HTML attribute
- `loading` — inline SVG spinner (`animate-spin`), `disabled` attribute, text preserved

**Props interface:**
```typescript
interface ButtonProps extends React.ButtonHTMLAttributes<HTMLButtonElement> {
  variant?: 'primary' | 'secondary' | 'outline' | 'text' | 'destructive'
  size?: 'sm' | 'md' | 'lg'
  fullWidth?: boolean
  loading?: boolean
  children: React.ReactNode
}
```

**Transition:** `transition-colors duration-150`
Already made instant under `prefers-reduced-motion` by globals.css block from AC-W1-03.

**Focus ring:** `focus:outline-none focus:ring-2 focus:ring-border-focus focus:ring-offset-2`

**Spinner:** SVG circle, `animate-spin`, `aria-hidden="true"`, sized per button height.

## Constraints That Apply

- **CW03** — `transition-colors` must be instant on `prefers-reduced-motion`.
  Already handled globally in `globals.css` from AC-W1-03.
