# Research: AC-W1-09 — Skeleton component

## Understanding

Build a `Skeleton` loading placeholder component with three shape variants
(`text-line`, `card`, `circle`). Each variant pulses opacity 0.4 → 0.7 → 0.4
over 1.5s to communicate loading state. The pulse must be suppressed when
`prefers-reduced-motion` is active.

The AC verification requires a Storybook story covering all three variants and
a story demonstrating the reduced-motion state (static, no pulse).

export interface SkeletonProps {

**Variant defaults (what each looks like without width/height overrides):**
- `text-line`: `w-full h-4` (1rem tall), `rounded-full`
- `card`: `w-full h-32` (128px tall), `rounded-card`
- `circle`: `w-10 h-10` (40px), `rounded-full` — results in a circle

**Animation class in globals.css:**

The `@keyframes progress-pulse` is already defined in globals.css with exactly the
spec values (0.4 / 0.7 / 0.4, 1.5s). Add a `.skeleton-pulse` class that reuses
this keyframe — guarded under `(prefers-reduced-motion: no-preference)`:

```css
@media (prefers-reduced-motion: no-preference) {
  .skeleton-pulse {
    animation: progress-pulse 1.5s ease-in-out infinite;
  }
}
```

## Constraints That Apply

- **CW01** — No raw hex or px in component file. `bg-blocked-light`, `rounded-card`,
  `rounded-full` are all valid Tailwind tokens.
- **CW02** — Storybook story required covering all variants.
- **CW03** — Animation MUST be off when `prefers-reduced-motion: reduce`. The `.skeleton-pulse`
  class is already guarded correctly via the `no-preference` media query in globals.css. The
  global reduced-motion block (`animation-duration: 0.01ms !important`) in globals.css
  provides a belt-and-suspenders fallback.
- No new constitutional constraints beyond those above.

## Ambiguities / Questions

**One minor ambiguity:** The AC says "reduced motion disabled" in the IMPLEMENT.md description,
and "reduced motion toggle test" in the spec. This is a Storybook story, not a Vitest unit test
(unit tests are AC-W1-14). The story must visually demonstrate what happens with reduced motion.
Storybook 8 supports `globals.reducedMotion` in story parameters for this purpose.

**Resolution (no blocker):** Implement a `ReducedMotion` story using
`parameters: { chromatic: { prefersReducedMotion: 'reduce' } }` plus a render decorator
that shows all three variants statically. This is consistent with the ProgressBar pattern.
