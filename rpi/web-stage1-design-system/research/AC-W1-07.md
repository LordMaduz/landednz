# Research: AC-W1-07 — Badge component with 5 variants

## Understanding

Build a `Badge` UI primitive with 5 variants covering phase labels, difficulty levels (easy/medium/hard), and premium status. Fully rounded pill shape (100px radius). Premium variant shows a lock icon. Storybook story covers all variants.

## Spec Discrepancy (resolved)

- **REQUEST.md** lists: `phase, difficulty-easy, difficulty-medium, difficulty-hard, premium`
- **15-web-build-specification.md** lists: `status, phase, premium, difficulty, source`

The REQUEST.md variant list is more specific and matches the mockup exactly. Using REQUEST.md as canonical. The 15-web-spec groups difficulty into one variant, but implementing as three discrete variants (easy/medium/hard) to allow simple usage: `<Badge variant="difficulty-easy">Easy</Badge>`.

## Constraints That Apply

- **CW03:** No animations in Badge, not applicable
