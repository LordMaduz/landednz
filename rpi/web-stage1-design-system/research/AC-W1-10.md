# Research: AC-W1-10 — StatusIndicator component

## Understanding

Build a `StatusIndicator` UI primitive that renders a circle-based icon for each of the
7 `TaskCardState` values. Two sizes: sm (16px) and md (24px). Each state has a distinct
icon shape and colour drawn from design tokens. Verified via a Storybook story showing
all 7 states × 2 sizes.

Icons are inline SVGs following the Badge.tsx precedent — no lucide-react dependency
needed (lucide-react is scheduled for Stage 2, not Stage 1).

## Functions / Routes / Tests

**Component API:**
```typescript
import type { TaskCardState } from '@/types/web'

export interface StatusIndicatorProps {
  state: TaskCardState
  size?: 'sm' | 'md'   // sm=16px, md=24px — default: 'md'
  className?: string
}
```

**State → icon + colour mapping (per 14-ui-ux-design.md):**

| State | Icon | Colour token |
|-------|------|-------------|
| `not_started` | Empty circle (border only) | `border-blocked` (text-tertiary #8E8E9A) |
| `in_progress` | Half-filled circle (left half) | `bg-primary` (#1B6B6D) |
| `complete` | Filled circle + white checkmark | `bg-success` (#2D8A5E) |
| `blocked` | Filled circle + lock | `bg-blocked` (#8E8E9A) |
| `premium_locked` | Filled circle + lock | `bg-secondary` = premium-gold (#D4A843) |
| `loading` | Pulsing grey circle (skeleton-pulse) | `bg-blocked-light` (#F2F2F4) |
| `error` | Filled circle + exclamation | `bg-error` (#C75B4A) |

**Icon implementation approach (inline SVG):**
- `not_started`: `<div>` with `rounded-full border-2 border-blocked` — no inner SVG
- `in_progress`: SVG with a semicircle path (D-arc) — left half filled primary, right half transparent with border
- `complete`: `bg-success rounded-full` containing a white checkmark SVG path
- `blocked`: `bg-blocked rounded-full` containing a white lock SVG path
- `premium_locked`: `bg-secondary rounded-full` containing a white lock SVG path (same as blocked)
- `loading`: `bg-blocked-light rounded-full skeleton-pulse` — no inner icon
- `error`: `bg-error rounded-full` containing a white exclamation `!` SVG path

**Size system:**
```typescript
const sizeStyles = {
  sm: { container: 'w-4 h-4', icon: 8 },   // 16px
  md: { container: 'w-6 h-6', icon: 12 },  // 24px
}
```

**Storybook stories:**
- `AllStates` — grid of all 7 states at md size with labels

- Individual stories: `NotStarted`, `InProgress`, `Complete`, `Blocked`, `PremiumLocked`, `Loading`, `Error`

## Constraints That Apply

- **CW01** — No raw hex in component. All colours via `bg-primary`, `bg-success`, `bg-blocked`,
  `bg-secondary`, `bg-error`, `bg-blocked-light`, `border-blocked` Tailwind tokens.
- **CW02** — Storybook stories required for all 7 states × 2 sizes.
- **CW03** — `loading` state uses `skeleton-pulse` class which is already gated under
  `prefers-reduced-motion: no-preference` in globals.css.
- **CW04** — `TaskCardState` imported from `@/types/web` (not duplicated).

## Ambiguities / Questions

**One clarification resolved internally:**
- `in_progress` half-filled circle: the spec says "left half filled." This is cleanest
  as a pure SVG using two semicircle paths — a filled left arc + a stroked right arc outline.
  No ambiguity; standard technique.
