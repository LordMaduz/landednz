# Research: AC-W1-01 — Next.js 14 project scaffolding

## Understanding

Create the `apps/web/` Next.js 14 App Router project from scratch with TypeScript strict mode. The AC is satisfied when `npx tsc --noEmit` in `apps/web/` returns zero errors. No components, no routes, no Tailwind tokens — just a compilable Next.js 14 skeleton that later ACs build upon.

Also required: add `apps/web` to root `package.json` workspaces and create `apps/web/CLAUDE.md`.

## Files Involved

**New files to create (minimal scaffold):**
- `apps/web/package.json` — Next.js 14 + React 18 + TypeScript deps
- `apps/web/tsconfig.json` — strict mode, Next.js paths
- `apps/web/next.config.ts` — minimal Next.js config
- `apps/web/tailwind.config.ts` — skeleton (tokens added in AC-W1-02)
- `apps/web/postcss.config.js` — Tailwind + autoprefixer
- `apps/web/src/app/layout.tsx` — minimal root layout
- `apps/web/src/app/page.tsx` — placeholder homepage
- `apps/web/src/app/globals.css` — Tailwind directives only (fonts + properties in AC-W1-03)
- `apps/web/public/.gitkeep` — placeholder for fonts (added in AC-W1-03)
- `apps/web/CLAUDE.md` — web-specific context

**Files to modify:**
- Root `package.json` — add `apps/web` to workspaces array

## Constraints That Apply

- **CW01** — No raw hex/px in component files. `tailwind.config.ts` is the exception.
- **CW04** — Web-specific types in `src/types/web.ts` — import from `@landednz/types` for shared types.
- **No localStorage for auth (CW06)** — not relevant at scaffolding stage, but tsconfig must allow SSR cookie helpers.
- TypeScript strict mode: `"strict": true` in tsconfig. No `any` without inline explanation.
- Node.js ≥ 22.0.0 (root engines constraint).
