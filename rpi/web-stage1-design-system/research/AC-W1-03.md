# Research: AC-W1-03 — globals.css CSS custom properties + DM Sans & DM Serif Display self-hosted

## Understanding

AC-W1-03 has three deliverables:
1. **Font files** — Download DM Sans (variable, 100–900) and DM Serif Display (Regular, 400) from Google Fonts and place them in `public/fonts/` as woff2 files. No CDN at runtime.
2. **@font-face declarations** — Add both @font-face blocks in `globals.css` with `font-display: swap`, pointing to `/fonts/`.
3. **CSS custom properties** — Add design token CSS vars (--font-display, --font-body, --text-*, colour vars) in `globals.css` as a fallback layer beneath Tailwind.
4. **Tailwind font family tokens** — Add `font-display` and `font-body` entries to `tailwind.config.ts` so `font-display` and `font-body` utility classes work.

Verification: both fonts render visually, DevTools Network shows zero requests to fonts.googleapis.com.
