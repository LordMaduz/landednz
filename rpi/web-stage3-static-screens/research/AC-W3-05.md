# Research: AC-W3-05 — Task rows: all 7 states

## Understanding

TaskRow.tsx already exists with 5 of 7 states. This AC adds the 2 missing states
(`loading` and `error`), fixes 2 existing inconsistencies against the spec, and adds
`TaskRow.stories.tsx` covering all 7 states.

The component is a hybrid-density list row: single border, ~44px height, consequence
line always visible, status icon on left, metadata + chevron on right.

## State gap analysis (current vs spec)

| State | Current | Spec | Delta |
|-------|---------|------|-------|
| not_started | ✅ Empty circle, bg-card | ✅ | — |
| in_progress | ✅ Half-filled, border-l-3 primary | ✅ | — |
| complete | ✅ Green check, opacity-70 | ✅ | — |
| blocked | ⚠️ bg-bg-card | blocked-light background | Fix bg |
| premium_locked | ✅ Gold lock, border-l-3 gold | ✅ | — |

**Hover state:** Current uses `hover:shadow-card-hover`. Spec says "No shadow on hover —
keep it flat: `border-hover` + `bg-primary-subtle`". Fix this too.

## Implementation details

### loading state
- StatusIcon: pulsing circle (skeleton-pulse animation, same class as Skeleton component)
- Name: pulsing bar at 60% width (`bg-border rounded animate-[skeleton-pulse_1.5s_ease-in-out_infinite] h-3 w-3/5`)
- Consequence: pulsing bar at 80% width (`h-2.5 w-4/5`)
- Background: bg-bg-card, no left border
- Right metadata: hidden (no clock/difficulty/chevron while loading)
- `aria-busy="true"` on the row

### error state
- StatusIcon: exclamation mark in error circle (`bg-error-light border border-error`, `!` in `text-error`)
- Background: `bg-error-light`
- Name: `text-text-primary font-semibold`
- Consequence/subtext: `"Something went wrong — tap to retry"` in `text-text-tertiary`
- Right metadata: hidden except chevron
- Row should have `onClick` capability (retry action)

### blocked state fix
- Add `isBlocked && 'bg-blocked-light'` to row className

### hover state fix
- Replace `hover:shadow-card-hover` with `hover:border-border-hover hover:bg-primary-subtle`
