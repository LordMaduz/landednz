# Research: AC-W3-15 — First-use hints: 3 sequential tooltips, dismiss reveals next

## Understanding

Build a first-use onboarding overlay system on the roadmap page: 3 sequential tooltip-style hints that appear one at a time on first visit. Dismissing one ("Got it") reveals the next. All state is in React state only for Stage 3 (localStorage persistence is Stage 5, AC-W5-13).

The existing `Tooltip.tsx` is a hover/focus tooltip — unsuitable here. A new `FirstUseHint` component is needed: a persistent, positioned callout with copy, arrow, and a "Got it" button.

**The 3 hints (from 14-ui-ux-design.md):**

| # | Target | Copy |
|---|--------|------|
| 1 | "Do these first" section | "Start here — tap any task to see what to do and why." |
| 2 | Sidebar Phase sections | "Your full plan is organised by phase. Each phase covers a specific time period." |
| 3 | Chat / Ask a question button | "Have questions? Our AI advisor knows your situation and can help." |

**Sequence:** Hint 1 visible on mount → "Got it" → Hint 2 visible → "Got it" → Hint 3 visible → "Got it" → all done (state: null).

## Ambiguities / Questions

**1. Hint 3 premium condition**
`14-ui-ux-design.md` says Hint 3 "Only appears if user is premium or on trial." In Stage 3 with mock data there is no real auth/premium state.

Recommendation: Show Hint 3 unconditionally in Stage 3 (consistent with the mock-everything approach of this stage). The premium condition is enforced in Stage 4 when real auth is wired.

**2. Hint 2 positioning — sidebar is outside RoadmapView**
Hint 2 targets the sidebar Phase sections, but the sidebar lives in `(app)/layout.tsx` outside `RoadmapView`. Rendering a positioned hint near the actual sidebar would require a React Portal + DOM measurement.

Recommendation: Render Hint 2 within the `RoadmapView` main content area with `position: left` arrow, positioned above the `FilterTabs` / phase list. The copy already explains phases clearly — the arrow direction is a visual aid, not a hard requirement for Stage 3.

**3. Hint anchor for Hint 3 — Chat button**
The `ChatWidget` (FAB) is rendered at the route level (`/roadmap/page.tsx`), also outside `RoadmapView`. 

Recommendation: Render Hint 3 within `RoadmapView` as a fixed/absolute positioned hint at the bottom-right corner, mimicking proximity to the ChatWidget FAB. Same Portal concern — keep it in-content for Stage 3.
