# Research: AC-W3-07 — Chat floating overlay

## Understanding

Build a floating chat widget using the Intercom Fin pattern — a 420×600px panel fixed to the bottom-right corner, rendered via React Portal so it never affects the two-column layout. When closed, show a 56px teal FAB. When open, the panel has a header, scrollable messages area, and an input row.

The mock conversation: opening message appears 500ms after mount (entry-point-aware); a "suggested question" chip shows; when user sends (or clicks chip), a thinking indicator cycles status lines → AI response appears with numbered steps, inline SourcePills, and a source footer.

All animations (panel slide-up, dot bounce, message fade-in) must live in `globals.css` inside `prefers-reduced-motion: no-preference` per CW03.

## Files Involved

**Create:**
- `apps/web/src/components/chat/ChatWidget.tsx` — Portal wrapper, manages `chatOpen` state, renders FAB or ChatPanel into `document.body`
- `apps/web/src/components/chat/ChatPanel.tsx` — 420×600 panel: header + scrollable messages + input row + mock conversation logic
- `apps/web/src/components/chat/ChatMessage.tsx` — AI variant (avatar + bubble + attribution + optional source footer) and User variant (right-aligned primary-light bubble)

**Modify:**
- `apps/web/src/app/globals.css` — add `slideUpPanel`, `typing` keyframes + `.chat-panel-enter`, `.typing-dot` classes inside `prefers-reduced-motion: no-preference`

## Functions / Routes / Tests

**ChatWidget.tsx:**
- `useState(false)` for `chatOpen`
- `useState(false)` for `mounted` — useEffect sets true (portal SSR guard)
- `createPortal(<FAB | ChatPanel />, document.body)`

**ChatPanel.tsx:**
- `useState<Message[]>([])` for messages
- `useState(false)` for `isThinking`
- `useState('')` for `thinkingStatus`
- `useState(0)` for `step` (0→1→2→3, drives demo flow)
- `useEffect` on mount → 500ms timeout → push opening AI message, set step=1
- `useEffect` on step===2 → simulate thinking (cycling status) → 2500ms → push AI response, step=3
- `useRef` for `messagesEndRef` + `useEffect` to auto-scroll
- `handleSend()` — appends user message, advances step

**Premium conversation flow (approved):**
- **Instant contextual opening**: AI message appears immediately based on entry point
  - From task detail: "I see you're looking at getting an IRD number. What would you like to know?"
  - From roadmap: "I can help with any of your settlement tasks. What's your question?"
  - From navigation: Generic greeting
- **Progressive disclosure**: 800ms → input focus indicator, 1500ms → suggested question chip fades in
- **Premium interactions**: token-by-token AI response (mocked), smart thinking status, smooth auto-scroll
- AI response: 5 numbered steps with inline SourcePills + warning callout + source footer
- Sources: "ird.govt.nz — Emergency tax", "ird.govt.nz — Tax code declaration IR330", "ird.govt.nz — Request early refund"

## Constraints That Apply

- **CW01** — all colours/spacing/radii via Tailwind tokens. No raw hex or px. The 4 chat-panel tokens are already in tailwind.config.ts. FAB size: `w-14 h-14` (56px standard Tailwind).
- **CW02** — ChatPanel.stories.tsx required with all states
- **CW03** — `slideUpPanel`, `typing` animations inside `prefers-reduced-motion: no-preference` media query
- **CW04** — `ChatEntryPoint` type imported from `@landednz/types` (already: `"TASK_CARD" | "ROADMAP" | "EMAIL_DEEPLINK" | "NAVIGATION"`)
- **Critical decision #4** — NOT a sidebar, NOT a third column. Floating overlay via React Portal.
- **Critical decision #5** — Two windows always. ChatWidget must not affect the flex layout.
