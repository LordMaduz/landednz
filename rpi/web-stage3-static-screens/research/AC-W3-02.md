# Research: AC-W3-02 — Onboarding: 5 questions, option cards highlight on select, progress bar fills

## Understanding

Build the interactive onboarding flow at `/onboarding`. The mockup has 3 phases:

1. **Scope screen** — entry before Q1: icon + DM Serif heading "5 quick questions to build your settlement plan" + "Takes about 2 minutes. No account needed." + "Let's go →" button
2. **Questions (5)** — fixed progress bar header + single question at a time, fade transitions between questions. Option cards highlight on click (primary border + primary-light bg + teal checkmark). Auto-advance 400ms after selection.
3. **Reveal stub** — after Q5, transition to AC-W3-03 reveal screen (this AC ends at question completion, handing off phase state to AC-W3-03)

**AC-W3-02 scope**: scope screen + progress bar + 5 questions with interactive option cards. The reveal transition animation is AC-W3-03.

**5 questions (from mockup):**
1. **Visa type** — 5 options mapping to `VisaType` from `@landednz/types`
2. **City** — 4 options mapping to `City` from `@landednz/types`
3. **Family situation** — 4 options mapping to `FamilySituation` from `@landednz/types`
4. **Occupation** — 7 options mapping to `Occupation` from `@landednz/types`
5. **Arrival timing** — 4 options mapping to `arrivalDate?: string` in `OnboardingState`

**Option card states (from mockup):**
- Default: `border-border bg-bg-card`
- Hover: `border-border-hover bg-primary-subtle -translate-y-px`
- Focus-visible: `ring-2 ring-border-focus`
- Selected: `border-primary bg-primary-light` + teal checkmark circle (animated `scaleIn`)
- Selected+hover: stays `bg-primary-light` (not overridden)

**Transitions between questions:**
- Exit: `fadeOutUp` (0.35s), then unmount
- Enter: `fadeInUp` (0.5s) on mount
- Option cards also animate in with staggered `fadeInUp`

**Progress bar:**
- Fixed at top, bg-bg/95 with backdrop blur
- Logo + "1 of 5" counter + 5 segmented bars (filled = primary, upcoming = border)
- Segments fill as user advances through questions

## Constraints That Apply

**CW01:** All styles via Tailwind. Option card selected/hover states use Tailwind conditional classes (not CSS `.selected` class). Need `scaleIn` animation token in globals.css.

**CW03:** All option card animations (`fadeInUp` stagger, `scaleIn` on selection) and question transitions (`fadeOutUp`/`fadeInUp`) must be under `@media (prefers-reduced-motion: no-preference)`. At reduced motion: instant transitions, no stagger delays.

**CW04:** Use `VisaType`, `City`, `FamilySituation`, `Occupation` from `@landednz/types`. `OnboardingState` already defined in `src/types/web.ts` — use it.

**CW05:** Mock data shape must match API shape. `OnboardingState.answers` already typed correctly with API types.
