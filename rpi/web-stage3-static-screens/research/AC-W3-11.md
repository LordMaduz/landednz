# Research: AC-W3-11 — Sidebar phases with task status indicators, Phase 3 Premium lock

## Understanding

The existing `Sidebar.tsx` (from Stage 2) has phase headers that toggle expand/collapse, but when expanded they show nothing — no task items. This AC wires up the full visual treatment:

1. **Expanded phases** (1 and 2): show a task list with `StatusIndicator` (sm, 16px) + truncated task name per task
2. **Phase headers** show `{completed}/{total}` count on the right for non-premium phases
3. **Phase 3 header**: replaces the Lock icon with a "Premium" badge pill (gold bg, gold text, pill shape)
4. **Phase 3 expanded**: shows nothing — same as mockup `{expanded && !phase.premium && (...)}`. Premium tasks aren't listed since they're locked.

The `StatusIndicator` component (Stage 1, `sm` size = 16px) is reused for task status dots in the sidebar. Mock task data is added directly in Sidebar.tsx (no mocks/ file needed — sidebar is layout, not a page).

2. **Lock icon removal**: Current Sidebar has `<Lock className="h-3 w-3 text-secondary hidden xl:block" />` for Phase 3. Replace with Premium badge (matches mockup), or keep both? → Mockup shows ONLY the Premium badge, no Lock icon. Remove Lock, add Premium badge.
