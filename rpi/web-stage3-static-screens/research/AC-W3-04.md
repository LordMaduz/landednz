# Research: AC-W3-04 — Roadmap dashboard: teal hero card, "Do these first", filter tabs

## Understanding

Build the main roadmap dashboard page at `/roadmap` using mock data. Three key visual zones:
1. **HeroCard** — teal gradient (primary → primary-dark), circular SVG progress ring, greeting, stats line
2. **"Do these first"** — top 3 non-complete / non-blocked / non-premium tasks with larger padding (priority variant)
3. **Filter tabs + phase sections** — tab row (All / To do / In progress / Done) above collapsible phase groups

The dashboard uses a content-replacement pattern (task click → TaskDetail replaces RoadmapList) per design decision #1, but TaskDetail is AC-W3-06. This AC wires only the list view.

## Functions / Components

### HeroCard
- Counts: `completed`, `inProgress`, `remaining` from mock tasks
- SVG circle: `r=30` in `72×72 viewBox`, `strokeDasharray={circumference}`, `strokeDashoffset` calculated from pct
- Progress stroke uses `text-secondary` (amber ring)
- Gradient: `from-primary to-primary-dark` (needs `primary-dark` token added to tailwind.config)
- Typography: DM Serif Display "Hi Priya", white/75 opacity subtitle, white/50 stats

### FilterTabs
- Props: `active: FilterValue`, `onChange: (v: FilterValue) => void`
- `FilterValue = 'all' | 'todo' | 'progress' | 'done'`
- Active state: `text-primary border-b-2 border-primary`
- Border sits on bottom of tabs, `border-b border-border` on container (tabs overlap -1px)

### PhaseSection
- Props: `phase: PhaseData`, `filter: FilterValue`, `onTaskClick: (task: TaskListItem) => void`
- Collapsible via local `useState(expanded)`
- Premium badge shown when `phase.isPremium = true`
- Completion count `X/Y` from tasks
- `phase.timeline` shown as secondary text (e.g. "Before you arrive")

### TaskRow (basic — enhanced in AC-W3-05)
- Props: `task: TaskListItem`, `priority?: boolean`, `onClick?: () => void`
- Status icon (circle variants) — inline SVG
- Consequence line / completed date / blocked-by text
- Time estimate badge
- Chevron right
- `priority=true` → `py-14px` (taller padding)
- `in_progress` → left border `border-l-3 border-primary`
- `premium_locked` → left border `border-l-3 border-secondary`

### RoadmapView (client component)
- State: `filter`, `selectedTask` (null for list, task for detail — detail deferred to AC-W3-06)
- Renders: `<HeroCard />` + "Do these first" section + `<FilterTabs />` + `<PhaseSection />` × 3
- "Do these first" only shown when `filter === 'all'`

### Mock data
- 3 phases (phase 1: 5 tasks, phase 2: 4 tasks, phase 3: 2 tasks premium)
- All 5 non-premium states represented: complete, in_progress, not_started, blocked
- Premium tasks in phase 3 with `isPremium: true, cardState: 'premium_locked'`
- Matches `TaskListItem` exactly (CW05)

## Constraints That Apply

- **CW01** — all styling via Tailwind tokens. Need to add `primary-dark: '#145254'` token for gradient. No arbitrary hex values in components.
- **CW03** — SVG progress ring `transition: stroke-dashoffset 0.6s ease-out` must be inside `@media (prefers-reduced-motion: no-preference)` in globals.css.
- **CW05** — mock data shape must exactly match `TaskListItem` from `src/types/web.ts`.
- **Design decision #1** — task click → content replacement (not right panel). AC-W3-04 stubs `onTaskClick` (no-op or TODO) since TaskDetail is AC-W3-06.
- **Design decision #2** — hero card is teal gradient + SVG circle ring (not plain text).
- **Body text 15px** — use `text-body` (0.9375rem), not `text-sm` or `text-base`.

- **"Hi Priya" hardcoded**: yes, Stage 3 is mock data only. Will be replaced with real user name in Stage 4.
- **Phase 3 premium locked**: in mockup, phase 3 tasks show premium_locked status and the whole phase has a "Premium" badge. Both are represented in mock data.
