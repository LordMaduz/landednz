# Research: AC-W3-08 — Premium gate inline card

## Understanding

Must build a premium gate card that appears inline within the roadmap view — specifically inside Phase 3 (Settling in), after the premium-locked task rows. The gate presents three equal-prominence paths:

1. **Upgrade** → "Continue with Premium — $49 for 6 months" (primary CTA, teal button)
2. **Defer** → "Remind me in 24 hours" (secondary outlined button)
3. **Decline** → "Stay on the free plan" (tertiary ghost link)

When user clicks **Decline**, the full gate card collapses to a smaller banner. The banner appears at the TOP of Phase 3 (between the Phase 3 header and the task rows). The gate card appears at the BOTTOM of Phase 3 (after the task rows).

State machine: `full` (default) → `banner` (after decline) → `dismissed` (after banner dismiss).

Visual design: gold top border (3px), subtle gold gradient overlay at top, star badge, amber anchor pricing box.

## Constraints That Apply

**CW01 (Design Tokens):** No raw hex values in component files. The gold gradient overlay must use `bg-premium-gradient` token (added to tailwind.config.ts), not `bg-[rgba(212,168,67,0.06)]`.

**CW02 (Storybook Required):** PremiumGateCard.stories.tsx must cover all 3 states.

**CW03 (Reduced Motion):** The collapse transition (full → banner) must be instant when `prefers-reduced-motion: reduce`. The `fadeInUp` appearance animation must also use `@media (prefers-reduced-motion: no-preference)`.

**CW05 (Mock Data Shape):** No new mock data file needed. Gate state is UI-only, managed in component state.
