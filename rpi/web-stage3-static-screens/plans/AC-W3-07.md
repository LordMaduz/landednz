# Implementation Plan: AC-W3-07 — Chat floating overlay

## Approach

Build a floating chat widget using React Portal so it never affects the two-column layout. `ChatWidget.tsx` is the portal wrapper managing `chatOpen` state — it renders either the FAB or `ChatPanel` into `document.body`. The panel is 420×600px (using existing Tailwind tokens `w-chat-panel`, `h-chat-panel`, `rounded-chat-panel`, `shadow-chat-panel`), fixed bottom-right. The premium UX flow: AI opening message appears instantly with entry-point context → 1500ms progressive disclosure shows a suggested question chip → user sends → thinking indicator cycles status → AI response renders token-by-token via a character-reveal interval. Two new keyframes added to `globals.css` inside `prefers-reduced-motion: no-preference`. Two new FAB shadow tokens added to `tailwind.config.ts`. `(app)/layout.tsx` adds `<ChatWidget />` after `<main>` (portal means zero layout impact).

6. Create `ChatPanel.tsx`:
   - `interface ChatPanelProps { onClose: () => void; entryContext?: ChatEntryPoint }`
   - State: `messages`, `input`, `isThinking`, `thinkingStatus`, `step`, `suggestVisible`, `revealIndex`
   - **Opening message** (useEffect on mount, 0ms):
     - `'TASK_CARD'` → "I see you're looking at getting an IRD number. What would you like to know about this step?"
     - `'ROADMAP'` → "I can help with any of your settlement tasks. What's your question?"
     - default → "Hi! I'm here to help with your New Zealand settlement journey. What would you like to know?"
     - Push AI message, set step=1
   - **Progressive disclosure** (useEffect on step===1): 1500ms → `setSuggestVisible(true)`
   - **Thinking simulation** (useEffect on step===2):
     - Immediately: `setIsThinking(true)`, status = "Checking IRD emergency tax rules..."
     - 1200ms: status = "Looking up refund process for overpaid PAYE..."
     - 2500ms: `setIsThinking(false)`, push full AI response with sources, step=3
   - **Token-by-token reveal**: useEffect watches `messages` — when last message is AI and `revealIndex < content.length`, setInterval(12ms) increments revealIndex
   - `messagesEndRef` + useEffect scrolls to bottom on messages/thinking change
   - Panel container: `fixed bottom-6 right-6 w-chat-panel h-chat-panel max-h-[calc(100vh-3rem)] bg-bg-card rounded-chat-panel border border-border shadow-chat-panel flex flex-col overflow-hidden z-[1000] chat-panel-enter`
   - Header: `px-4 py-4 border-b border-border flex items-center gap-2.5 flex-shrink-0`
     - Avatar 34×34, title "LandedNZ Advisor" (`text-small font-semibold`), subtitle (`text-caption text-text-tertiary`), close button
   - Messages: `flex-1 overflow-y-auto px-3 py-4 space-y-0`
   - Suggested chip (when suggestVisible): `text-caption text-text-tertiary uppercase tracking-wide` label + button with `border border-border rounded-button text-small text-text-secondary hover:border-primary hover:text-primary`
   - Input: `border-t border-border px-3.5 py-3 flex-shrink-0`
     - Container: `flex items-end gap-2 bg-bg rounded-xl px-3.5 py-2.5 border border-border focus-within:border-border-focus transition-colors`
     - Textarea: rows=1, max-height 72px, `text-small leading-body bg-transparent resize-none outline-none`
     - Send button: `w-8 h-8 rounded-full bg-primary flex items-center justify-center flex-shrink-0 disabled:opacity-40 hover:bg-primary-hover transition-colors`
   - Disclaimer: `text-caption text-text-tertiary text-center mt-2`
