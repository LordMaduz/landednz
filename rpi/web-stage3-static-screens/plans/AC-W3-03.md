# Implementation Plan: AC-W3-03 — Roadmap reveal transition with reduced motion fallback

## Approach
Replace the "Building your plan..." placeholder in OnboardingFlow.tsx with a full
RoadmapReveal component. The component manages two internal phases: a loading sequence
(4 personalized messages at 600ms intervals with 3 pulsing dots) and a success state
(animated checkmark + "Your plan is ready" + summary + CTA). Messages are derived from
OnboardingState answers with graceful fallbacks for missing values. State persistence
uses Zustand store (not localStorage) — 'revealComplete' flag in a lightweight
onboarding store persists for the session. A custom useReducedMotion() hook detects
prefers-reduced-motion: reduce and skips the sequence entirely, showing the success
state instantly. All CSS animations scoped under @media (prefers-reduced-motion: no-preference).
CTA navigates to /roadmap via Next.js router.

## File Changes
- Modify `apps/web/src/app/globals.css` — add `@keyframes pulseGlow`, `@keyframes revealTextIn`, `@keyframes checkDraw` under `@media (prefers-reduced-motion: no-preference)` block
- Create `apps/web/src/lib/hooks/useReducedMotion.ts` — hook reading window.matchMedia for prefers-reduced-motion
- Create `apps/web/src/lib/stores/onboardingStore.ts` — Zustand store with revealComplete flag
- Create `apps/web/src/components/onboarding/RoadmapReveal.tsx` — full reveal component, uses useReducedMotion() to skip sequence, reads/writes Zustand store
- Modify `apps/web/src/components/onboarding/OnboardingFlow.tsx` — replace reveal placeholder with `<RoadmapReveal answers={answers} />`
