## Story Patterns Reference

**No-prop components** (Sidebar, MobileNav, OnboardingFlow, RoadmapView):
```typescript
export const Default: Story = {}
```

**Full-width sections** (all marketing):
```typescript
parameters: { layout: 'fullscreen' }
decorators: [(Story) => <div className="bg-hero-gradient"><Story /></div>]
```

**Components with required callbacks** (PremiumBanner, DeleteModal, etc.):
```typescript
args: { onUpgrade: () => {}, onDismiss: () => {} }
```

**Mock data import** (CW05 compliance):
```typescript
import { MOCK_PHASES } from '@/mocks/roadmap'
import { MOCK_ONBOARDING_ANSWERS } from '@/mocks/settings'
```
