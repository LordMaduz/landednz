# Implementation Plan: AC-W3-15 — First-use hints: 3 sequential tooltips, dismiss reveals next

## Approach
Create a new `FirstUseHint` component — a persistent tooltip-style callout with message, directional arrow, and a "Got it" dismiss button. Add `activeHint: 1 | 2 | 3 | null` state to `RoadmapView` (initialised to `1`). Render each hint anchored to its target element using relative positioning; Hint 3 uses `fixed` positioning to sit above the ChatWidget FAB (which lives outside RoadmapView). Dismissing via "Got it" advances through the sequence: 1 → 2 → 3 → null. All state is React-local — no localStorage (that's AC-W5-13). Entrance animation respects `prefers-reduced-motion` (CW03).

Confirmed decisions from research:
- Hint 3 shown unconditionally in Stage 3 (premium condition deferred to Stage 4)
- Hint 2 rendered within content area with left-facing arrow (avoids Portal complexity)
- Hint 3 rendered as fixed bottom-right (mimics FAB proximity without Portal)

## Implementation Order

1. **Create `FirstUseHint.tsx`**
   - Props: `{ message: string; position?: 'top' | 'bottom' | 'left' | 'right'; onDismiss: () => void; className?: string }`
   - Renders: hint bubble (`bg-text-primary text-text-inverse shadow-dropdown rounded-card max-w-[260px] p-4`), directional arrow (4×4 `rotate-45` square, same bg, positioned per `position` prop), "Got it" button (`text-secondary font-medium hover:text-text-inverse/75 transition-colors`)
   - Entrance: `animate-[fadeIn_0.2s_ease-out] motion-reduce:animate-none` (CW03)
   - Arrow positions: `bottom` → arrow at top-center; `top` → arrow at bottom-center; `right` → arrow at left-center; `left` → arrow at right-center

2. **Modify `RoadmapView.tsx`**
   - Add state: `const [activeHint, setActiveHint] = useState<1 | 2 | 3 | null>(1)`
   - Add handler: `const dismissHint = () => setActiveHint(h => h === 1 ? 2 : h === 2 ? 3 : null)`
   - **Hint 1**: wrap "Do these first" `<h2>` in `relative` div → render `<FirstUseHint message="Start here — tap any task to see what to do and why." position="bottom" onDismiss={dismissHint} />` when `activeHint === 1`
   - **Hint 2**: add `relative` wrapper around `<FilterTabs>` → render `<FirstUseHint message="Your full plan is organised by phase. Each phase covers a specific time period." position="bottom" onDismiss={dismissHint} />` when `activeHint === 2`
   - **Hint 3**: render `<FirstUseHint message="Have questions? Our AI advisor knows your situation and can help." position="top" onDismiss={dismissHint} className="fixed bottom-24 right-6 z-40" />` when `activeHint === 3`
