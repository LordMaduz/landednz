# Implementation Plan: AC-W3-09

## Approach
Build the Settings page with four section cards (Profile, Subscription, Notifications, Account). Decompose into six small components: SectionCard, FieldRow, Toggle, RadioOption, DeleteModal, and SettingsView. All state lives in SettingsView (three useState hooks). Mock data goes in `src/mocks/settings.ts`. Two Tailwind tokens are added to tailwind.config.ts, and a `.scale-in` CSS utility class is added to globals.css (inside `@media (prefers-reduced-motion: no-preference)` guard using the existing `scaleIn` keyframe). The existing page stub is replaced with a SettingsView import.
