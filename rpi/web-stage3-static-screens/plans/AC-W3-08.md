# Implementation Plan: AC-W3-08 — Premium gate inline card

## Approach

Build two new React components (`PremiumGateCard` and `PremiumBanner`) that integrate into Phase 3 of the roadmap via optional `topSlot`/`bottomSlot` props added to `PhaseSection`. Gate state (`full | banner | dismissed`) lives in `RoadmapView`. The card renders after Phase 3 premium-locked task rows (bottomSlot); the banner renders before them (topSlot). Both Defer and Decline collapse the card to the banner. Visual spec taken directly from `mockup-screens/landednz-screen-premium-gate.jsx`. One new tailwind token (`bg-premium-gradient`) required.

### RoadmapView wiring

```typescript
const [gateState, setGateState] = useState<PremiumGateState>('full')

// In phases map:
<PhaseSection
  key={phase.num}
  phase={phase}
  filter={filter}
  onTaskClick={...}
  defaultExpanded={i < 2}
  topSlot={
    phase.num === 3 && gateState === 'banner' && filter === 'all'
      ? <PremiumBanner onUpgrade={() => {}} onDismiss={() => setGateState('dismissed')} />
      : undefined
  }
  bottomSlot={
    phase.num === 3 && gateState === 'full' && filter === 'all'
      ? <div className="mt-3">
          <PremiumGateCard
            onUpgrade={() => {}}
            onDefer={() => setGateState('banner')}
            onDecline={() => setGateState('banner')}
          />
        </div>
      : undefined
  }
/>
```
