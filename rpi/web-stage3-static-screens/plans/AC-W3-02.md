# Implementation Plan: AC-W3-02 — Onboarding: 5 questions, option cards highlight on select, progress bar fills

## Approach
Replace the `/onboarding` stub with a fully interactive 3-phase client-side flow. Phase state (`scope | questions | reveal`) is managed in `OnboardingFlow.tsx` using `useState`. Five components handle the UI: `ScopeScreen` (entry), `OnboardingProgressBar` (fixed header), `QuestionView` (per-question container), and `OptionCard` (selectable card). Answer values are stored using `@landednz/types` (VisaType, City, FamilySituation, Occupation) and the `OnboardingState` interface already defined in `src/types/web.ts` — CW04/CW05 compliant. Option card selected/hover/focus states are handled with Tailwind conditional class strings (no CSS class toggling). Question transitions use CSS animations (`fadeOutUp` exit → 350ms → `fadeInUp` enter) scoped under `@media (prefers-reduced-motion: no-preference)` in `globals.css`. AC-W3-02 ends when the 5th answer is submitted and `phase` is set to `'reveal'` — a minimal "Building your plan..." placeholder is shown; AC-W3-03 will replace it with the full animated reveal.
