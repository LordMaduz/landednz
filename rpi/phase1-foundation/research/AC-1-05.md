# Research: AC-1-05 — supabase start, all services running

## Understanding

AC-1-05 is pure infrastructure — no TypeScript code to write.
The Supabase CLI (v2.75.0, installed at /opt/homebrew/bin/supabase) must be initialised
in the project root and the local Supabase stack started. Verification is:
`supabase status` shows all services running (Studio, API, DB, Auth, Storage, etc.).

The project has no `supabase/` directory yet — `supabase init` must be run first.

**Architecture note:** Supabase local runs its OWN Docker containers on its own ports
(API on 54321, DB on 54322). This is SEPARATE from our app's docker-compose PostgreSQL
on port 5432. The two stacks never share a database. Our Prisma schema lives on the
docker-compose Postgres; Supabase manages `auth.users` on its own Postgres.

**Why this matters for later ACs:**
- AC-1-08 (`POST /auth/verify`) needs `SUPABASE_JWT_SECRET` from `supabase status`
- AC-1-06 (Google OAuth) needs the anon key and redirect URL from the local Supabase instance

## Files Involved

**Generated by supabase init:**
- `supabase/config.toml` — Supabase project configuration
- `supabase/.gitignore` — auto-generated

**No TypeScript files created or modified.**

## Functions / Routes / Tests

None — this is an operations AC. The full verification is:
```
supabase init         # initialise project (once)
supabase start        # start all local services
supabase status       # verify all services show "running"
```

Output to capture from `supabase status`:
- API URL (e.g. http://127.0.0.1:54321)
- anon key
- JWT secret → must be saved to .env.local as SUPABASE_JWT_SECRET

## Constraints That Apply

- **CLAUDE.md gotcha:** `supabase start` — NOT docker-compose. Supabase CLI manages its
  own containers. Do NOT add any Supabase service to `docker-compose.yml`.
- **CLAUDE.md gotcha:** JWT secret from `supabase status` → `.env.local` as
  `SUPABASE_JWT_SECRET`. Mismatch = all auth silently fails with 401.
- **CLAUDE.md gotcha:** Local and production anon keys are different. Never mix them.

No constitution constraints apply — no AI, no DB queries, no Fastify, no SDK.
