# Research: AC-1-06 — Google OAuth end-to-end on iOS Simulator

## Understanding

Complete the Google OAuth sign-in flow so that:
1. A user taps "Sign in with Google" in the iOS Simulator
2. Safari opens with the Supabase OAuth URL → user authenticates with Google
3. Supabase creates an `auth.users` record and redirects to `landednz://auth/callback#access_token=...&refresh_token=...`
4. The app receives the deep link, calls `supabase.auth.setSession()`, then `POST /auth/verify`
5. App DB `User` record is created; `App.tsx` shows the tab navigator

The API side (`POST /auth/verify`) is already implemented and PASS (AC-1-08/09).
The app was migrated from Expo to **React Native CLI** in AC-1-15 — previous research referencing
`expo-web-browser`, `expo-auth-session`, and `EXPO_PUBLIC_*` env vars is **no longer valid**.

Supabase is configured as the OAuth proxy to Google. `react-native-app-auth` (standard PKCE library)
is NOT the right tool here — Supabase mediates the Google OAuth and returns its own JWT.
The correct approach is: Supabase `signInWithOAuth` → `Linking.openURL` → deep link callback.

Verification: live interactive flow on iOS Simulator — not a unit test.

## Functions / Routes / Tests

**OAuth flow:**
```
1. LoginScreen: tap "Sign in with Google"
2. signInWithGoogle() in useAuth.ts:
   → supabase.auth.signInWithOAuth({ provider: 'google', options: { redirectTo: 'landednz://auth/callback', skipBrowserRedirect: true } })
   → Linking.openURL(data.url)  ← opens Safari with Supabase OAuth URL
3. User consents in Safari → Supabase creates auth.users → Supabase redirects to:
   landednz://auth/callback#access_token=...&refresh_token=...
4. iOS deep link fires → AppDelegate openURL:options: → RCTLinkingManager → Linking event
5. useAuth Linking listener: parse hash fragment → supabase.auth.setSession({ access_token, refresh_token })
6. onAuthStateChange fires → session state updates → App.tsx shows tab navigator
7. authVerify(access_token) → POST /auth/verify → app DB User record created
```

**`Info.plist` change:**
```xml
<key>CFBundleURLTypes</key>

```

**`AppDelegate.mm` addition:**
```objc
#import <React/RCTLinkingManager.h>

- (BOOL)application:(UIApplication *)application
   openURL:(NSURL *)url
   options:(NSDictionary<UIApplicationOpenURLOptionsKey,id> *)options
{
  return [RCTLinkingManager application:application openURL:url options:options];
}
```

**`useAuth.ts` — `signInWithGoogle()` implementation:**
```typescript
async function signInWithGoogle(): Promise<void> {
  setState((prev) => ({ ...prev, loading: true, error: null }))
  try {
    const { data, error } = await supabase.auth.signInWithOAuth({
      provider: 'google',
      options: {
        redirectTo: 'landednz://auth/callback',
        skipBrowserRedirect: true,
      },
    })
    if (error || !data.url) throw error ?? new Error('No OAuth URL')
    await Linking.openURL(data.url)
  } catch (err) {
    const message = err instanceof Error ? err.message : 'Sign in failed'
    setState((prev) => ({ ...prev, loading: false, error: message }))
  }
}
```

**`useAuth.ts` — deep link listener in `useEffect`:**
```typescript
const handleDeepLink = async ({ url }: { url: string }) => {
  if (!url.startsWith('landednz://auth/callback')) return
  const hashParams = new URLSearchParams(url.split('#')[1] ?? '')
  const accessToken = hashParams.get('access_token')
  const refreshToken = hashParams.get('refresh_token')
  if (!accessToken || !refreshToken) return
  const { error } = await supabase.auth.setSession({ access_token: accessToken, refresh_token: refreshToken })
  if (error) { setState((prev) => ({ ...prev, loading: false, error: error.message })); return }
  await authVerify(accessToken).catch((e) => console.error('authVerify failed', e))
}
const sub = Linking.addEventListener('url', handleDeepLink)
return () => sub.remove()
```

**`App.tsx` auth gate:**
```tsx
const { session, loading } = useAuth()
if (loading) return <ActivityIndicator />
if (!session) return <LoginScreen onGoogleSignIn={signInWithGoogle} ... />
return <NavigationContainer>...</NavigationContainer>
```
