# Research: AC-1-07 — Apple Sign-In configured in iOS project

## Understanding

AC-1-07 is **configuration only** — Apple Sign-In does not need to function in simulator.
The goal is to ensure the iOS project has Apple Sign-In properly wired at the native layer
so a production build can include it without rejection by App Store guideline 4.8
(mandatory when Google Sign-In is offered).

Three things need to be in place:
1. npm package `@invertase/react-native-apple-authentication` installed (provides native RN bindings)
2. Xcode entitlements file with `com.apple.developer.applesignin` capability
3. Xcode project references the entitlements file for the LandedNZ target

The LoginScreen already has the Apple Sign-In button stubbed (disabled, labelled "coming soon")
with a comment referencing AC-1-07 — the UI exists, we just need the native layer configured.

The AppDelegate.mm does **not** need modification — `@invertase/react-native-apple-authentication`
uses auto-linking and does not require AppDelegate changes in modern React Native.

## Files Involved

**New files to create:**
- `apps/mobile/ios/LandedNZ/LandedNZ.entitlements` — entitlements file with Apple Sign-In capability

**Modified files:**
- `apps/mobile/package.json` — add `@invertase/react-native-apple-authentication`
- `apps/mobile/ios/LandedNZ.xcodeproj/project.pbxproj` — reference entitlements file in target build settings

**Unchanged:**
- `apps/mobile/ios/LandedNZ/AppDelegate.mm` — no changes needed (auto-linking handles it)
- `apps/mobile/src/screens/LoginScreen.tsx` — Apple button already stubbed, stays disabled

## Functions / Routes / Tests

No functions, routes, or tests. This is purely native iOS configuration.

**Verification (per spec):** Inspect the Xcode project to confirm:

## Constraints That Apply

- **App Store guideline 4.8**: Apple Sign-In mandatory when Google Sign-In is offered — AC-1-07 sets up the foundation.
- **Bundle ID**: `com.landednz.app` must match the entitlements and any Apple Developer config exactly.
- **Configuration only**: Does not need to function — simulator cannot test Apple Sign-In payment/auth flows.
