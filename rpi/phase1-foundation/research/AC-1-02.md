# Research: AC-1-02 — prisma migrate dev clean, all Section 1 tables exist

## Understanding

Create the Prisma schema from Section 1 of `12-build-specification.md` and run `npx prisma migrate dev` against the Docker PostgreSQL instance (from AC-1-01). After migration, all tables in the schema must exist in the database.

This AC also requires the minimum monorepo scaffolding to make Prisma runnable:
- Root `package.json` with npm workspaces config
- `apps/api/package.json` with Prisma as a dependency
- `apps/api/tsconfig.json` for TypeScript

The full `src/` directory structure (routes, services, features) is NOT required here — that's deferred to later ACs (AC-1-03 onwards for routes, AC-1-11 for TypeScript compilation).

**On the `embedding vector(1536)` column:**
The spec (§3 schema notes, line 339) is explicit: "pgvector embedding column added via raw SQL in migration — see Phase 5 spec." This means Phase 1 creates the `KnowledgeBaseChunk` table WITHOUT the embedding column. The raw SQL migration that adds `embedding vector(1536)` is Phase 5 work. The Prisma schema comment documents this deferred column but does not declare it.
