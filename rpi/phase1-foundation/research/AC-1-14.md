# Research: AC-1-14 — seed scaffold runs without error

## Understanding

Create a scaffold for `apps/api/scripts/seed-knowledge-base.ts` that:
- Defines the `TaskSeedEntry` interface per spec §2.3 (the data shape used in Phase 2)
- Contains an empty `tasks` array (placeholder — real content delivered in AC-2-15)
- Connects to the DB via Prisma, iterates the empty array (no writes), logs results, disconnects cleanly
- Runs without error when invoked as `npx ts-node scripts/seed-knowledge-base.ts` from `apps/api/`

The AC criteria is: **connects to DB and executes without crashing**. Phase 1 scope is structure only.
Phase 2 (AC-2-15) fills in all 21 tasks and both persona variants.
