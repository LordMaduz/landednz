The critical blocker is the missing `ios/` directory. React Native CLI apps require a native
Xcode project to build and run on the simulator. Without `ios/`, `npx react-native run-ios`
fails immediately.

## Functions / Routes / Tests

**App.tsx — navigator:**
```tsx
import React from 'react'
import { NavigationContainer } from '@react-navigation/native'
import { createBottomTabNavigator } from '@react-navigation/bottom-tabs'
import { RoadmapScreen } from './src/screens/RoadmapScreen'
import { ChatScreen } from './src/screens/ChatScreen'
import { ProfileScreen } from './src/screens/ProfileScreen'

const Tab = createBottomTabNavigator()

export default function App() {
  return (
    <NavigationContainer>
      <Tab.Navigator>
        <Tab.Screen name="Roadmap" component={RoadmapScreen} />
        <Tab.Screen name="Chat" component={ChatScreen} />
        <Tab.Screen name="Profile" component={ProfileScreen} />
      </Tab.Navigator>
    </NavigationContainer>
  )
}
```

**iOS project generation strategy:**
1. Run `npx react-native@0.76.1 init LandedNZTemp --directory /tmp/LandedNZTemp --skip-install`
2. Copy `/tmp/LandedNZTemp/ios/` → `apps/mobile/ios/`
3. Replace `LandedNZTemp` bundle ID with `com.landednz.app` in `Info.plist` and `.xcodeproj`
4. Run `cd apps/mobile/ios && pod install`
5. Clean up `/tmp/LandedNZTemp`

**Verification:**
`npx react-native run-ios` — app launches in iOS Simulator, three tabs visible (Roadmap / Chat / Profile).
