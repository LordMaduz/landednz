# Implementation Plan: AC-1-07

## Approach
Configuration-only AC — Apple Sign-In does not need to function in simulator. The goal is to wire Apple Sign-In at the native iOS layer so a production build includes it without App Store rejection (guideline 4.8 — mandatory when Google Sign-In is offered). Install the `@invertase/react-native-apple-authentication` npm package, create an Xcode entitlements file with the `com.apple.developer.applesignin` capability, and reference the entitlements file from the Xcode project's build settings. AppDelegate.mm requires no changes — the package uses auto-linking. No UI changes needed — LoginScreen button is already stubbed and disabled.

## File Changes
- CREATE `apps/mobile/ios/LandedNZ/LandedNZ.entitlements` — Apple Sign-In entitlements
- MODIFY `apps/mobile/package.json` — add `@invertase/react-native-apple-authentication`
- MODIFY `apps/mobile/ios/LandedNZ.xcodeproj/project.pbxproj` — add entitlements reference under `CODE_SIGN_ENTITLEMENTS` for both Debug and Release configurations
- RUN `cd apps/mobile/ios && pod install` — install native pod for the package

## Implementation Order
1. Install npm package: `npm install @invertase/react-native-apple-authentication`
2. Create `LandedNZ.entitlements` with `com.apple.developer.applesignin` capability
3. Update `project.pbxproj` to reference entitlements file in build settings
4. Run `pod install` to link native module
5. Verify by inspection (no functional test required)
