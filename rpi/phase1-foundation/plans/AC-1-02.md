## Approach

Create the minimum monorepo scaffolding (root `package.json` with npm workspaces, `apps/api/package.json` with Prisma dependencies, `apps/api/tsconfig.json`) and the full Prisma schema from Section 1 of the build spec. Then run `npx prisma migrate dev --name init` to generate the migration and create all tables.

6. Create `.env.local` with DATABASE_URL (gitignore already in place from AC-1-01)
