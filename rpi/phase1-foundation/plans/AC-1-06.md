# Implementation Plan: AC-1-06

## Approach

Implement Google OAuth end-to-end for iOS Simulator using React Native CLI. The approach uses Supabase's `signInWithOAuth` (which acts as an OAuth proxy to Google) combined with React Native's `Linking` API for the deep link callback — no new native OAuth modules required.

Before the OAuth flow can work, two gaps must be fixed:
1. **Missing `babel.config.js`** — React Native CLI needs this to process JSX/TS; without it nothing compiles
2. **Stale `.env` vars** — `.env` still has `EXPO_PUBLIC_*` prefixes from before AC-1-15 migration; `supabase.ts` reads `SUPABASE_URL` and `SUPABASE_ANON_KEY`

Fix: install `react-native-dotenv`, create `babel.config.js`, add `env.d.ts` TypeScript declaration, and update `.env`. Then register the `landednz://` URL scheme in `Info.plist`, add `openURL:options:` to `AppDelegate.mm`, implement `signInWithGoogle()` + deep link listener in `useAuth.ts`, and add an auth gate to `App.tsx`.

## Key Technical Details

**`babel.config.js`:**
```js
module.exports = {
  presets: ['module:@react-native/babel-preset'],
  plugins: [
    ['module:react-native-dotenv', {
      envName: 'APP_ENV',
      moduleName: '@env',
      path: '.env',
      allowUndefined: false,
    }],
  ],
}
```

**OAuth flow in `useAuth.ts`:**
```
signInWithGoogle()
→ supabase.auth.signInWithOAuth({ provider: 'google', options: { redirectTo: 'landednz://auth/callback', skipBrowserRedirect: true } })
→ Linking.openURL(data.url)   ← opens Safari with Supabase OAuth URL
→ user consents in Safari → Supabase creates auth.users → redirects to landednz://auth/callback#access_token=...
→ AppDelegate openURL:options: → RCTLinkingManager → Linking event fires
→ handleDeepLink: parse hash → supabase.auth.setSession() → authVerify(accessToken)
→ onAuthStateChange fires → session set → App.tsx re-renders → tab navigator shown
```

**Deep link URL format:** Supabase redirects with hash fragment (not query params):
`landednz://auth/callback#access_token=...&refresh_token=...&token_type=bearer`
Parse via `url.split('#')[1]` → `new URLSearchParams(fragment)`.
