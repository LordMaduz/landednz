## Key Technical Details

**OAuth flow in `useAuth.ts`:**
```
signInWithOAuth({ provider: 'google', skipBrowserRedirect: true })
→ WebBrowser.openAuthSessionAsync(authUrl, redirectUri)
→ result.url contains: landednz://auth/callback#access_token=...&refresh_token=...
→ parse hash fragment → supabase.auth.setSession({ access_token, refresh_token })
→ onAuthStateChange fires → session state updates → App.tsx re-renders → tab nav shown
→ authVerify(access_token) → POST /auth/verify → User record in app DB
```

**`makeRedirectUri({ scheme: 'landednz' })`** generates `landednz://auth/callback` — works in iOS simulator via `ASWebAuthenticationSession` even in Expo Go.
