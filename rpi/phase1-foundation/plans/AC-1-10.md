# Implementation Plan: AC-1-10

## Approach

Generate the missing iOS native Xcode project using `npx react-native@0.76.1 init LandedNZ
--skip-install` in `/tmp`, copy the resulting `ios/` directory into `apps/mobile/ios/`,
update the bundle identifier to `com.landednz.app` in both `Info.plist` and
`project.pbxproj`, run `pod install`, then rewrite `App.tsx` to wire up a three-tab bottom
navigator (Roadmap / Chat / Profile) using @react-navigation/bottom-tabs. The placeholder
screens and all other config files already exist from AC-1-15.

## Implementation Order

1. Generate iOS project in temp dir:
   `cd /tmp && npx react-native@0.76.1 init LandedNZ --skip-install`
2. Copy `ios/` to `apps/mobile/`:
   `cp -r /tmp/LandedNZ/ios /Users/ruchira/Development/landednz/apps/mobile/ios`
3. Update bundle identifier in `ios/LandedNZ/Info.plist` — set `CFBundleIdentifier` to `com.landednz.app`
4. Update bundle identifier in `ios/LandedNZ.xcodeproj/project.pbxproj` — replace all occurrences of generated ID with `com.landednz.app`
5. Install npm deps: `cd apps/mobile && npm install`
6. Run CocoaPods: `cd apps/mobile/ios && pod install`
7. Rewrite `App.tsx` with NavigationContainer + createBottomTabNavigator + 3 tab screens
8. Verify TypeScript: `cd apps/mobile && npx tsc --noEmit`
9. Launch on simulator: `npx react-native run-ios`

## Test Strategy

Visual verification — `npx react-native run-ios` must produce:
- iOS Simulator opens without crash
- App renders (not a white screen)
- Bottom tab bar visible with 3 tabs: **Roadmap**, **Chat**, **Profile**
- Tapping each tab navigates to the corresponding placeholder screen

Secondary: `npx tsc --noEmit` in `apps/mobile` — zero errors.
