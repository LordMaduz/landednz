# Implementation Plan: AC-1-10

## Approach
Bootstrap `apps/mobile` from scratch as a managed Expo project (SDK 52). Create `app.json`, `package.json`, `tsconfig.json`, and `index.ts` entry point. Wire up `App.tsx` with React Navigation's `NavigationContainer` + `createBottomTabNavigator` showing three placeholder screens: Roadmap, Chat, Profile. No product logic — each screen renders its name as centred text. The app must launch in Expo Go without any custom native modules.

## Implementation Order

1. `app.json` — Expo config with name, slug, SDK version, `bundleIdentifier: com.landednz.app`
2. `package.json` — expo ~52.0.0, react-navigation, react-native-screens, react-native-safe-area-context, TypeScript devDeps
3. `npm install` — in `apps/mobile`
4. `tsconfig.json` — extend `expo/tsconfig.base`
5. Three placeholder screens — RoadmapScreen, ChatScreen, ProfileScreen (identical centred text pattern)
6. `App.tsx` — `NavigationContainer` + `createBottomTabNavigator` mounting the three screens
7. `index.ts` — `registerRootComponent(App)`
