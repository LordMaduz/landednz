# AI Search (Brand SEO Phase D) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (inline; tasks are mechanical) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** ChatGPT, Perplexity, Claude and Google AI can read, quote and cite LandedNZ's 27 public guides, and we can measure it.

**Architecture:** No new content and no AI at runtime. The existing `guides()` / `guide(slug)` data (apps/web/src/lib/guides.ts) is rendered a second way, as Markdown, and served at `/llms.txt` and `/llms-full.txt`. The Article JSON-LD gains `citation` links to the official sources. Crawler access is pinned by a test, then verified on the live site.

**Tech Stack:** Next.js route handlers (`force-static`), Vitest, `npx is-agentic`, curl.

**Spec:** `docs/superpowers/specs/2026-11-01-brand-seo-design.md` (Roadmap: D), `docs/superpowers/specs/2026-11-01-public-guides-design.md`. Branch `feat/ai-search`, from `feat/public-guides` (PR #23). Rebase onto main once #23 merges. Release after v1.2.0.

## Global Constraints

- Content stays one copy for people and machines. No separate "AI-only" text (Google's guide: scaled content abuse). The Markdown is the same fields as the page, in the same order.
- Only items without `when` are shown (G6). Stale content fails the build (G4): the Markdown uses `guides()` / `guide()`, which already throw.
- No `HowTo`, no `FAQPage` schema (public-guides spec, SEO section).
- No new dependency. No commit trailers naming Claude.
- Robots: one `User-agent: *` group, no named-agent groups, unless the owner decides a training opt-out (see Task 3).
- Absolute URLs come from `SITE_URL` (apps/web/src/lib/site.ts).
- Owner-facing checklists and the baseline sheet stay local and gitignored.

## Review Focus

- A guide with an empty section (no documents, no cost) must not emit an empty heading in the Markdown.
- Text containing `<`, backticks or `|` must pass through unescaped and unbroken in the Markdown (plain text, not HTML).
- Dev/preview builds have `SITE_URL=http://localhost:3000`; llms files must never hard-code `landednz.co.nz`.
- A new task added to `GUIDE_SLUGS` appears in both llms files with no further edit.
- Vercel bot protection or a WAF rule returning 403 to AI user agents (robots.ts alone would pass).
