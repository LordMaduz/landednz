# Brand SEO (entity hub + off-site kit) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Google read LandedNZ as one entity (name, logo, bio, profiles) so landednz.co.nz wins the "LandedNZ" query, and give the owner a ready kit for the off-site profiles.

**Architecture:** One brand source (`src/lib/brand.ts`) feeds metadata, a JSON-LD `@graph` on the home page and a new /about page. The logo PNG is a Next route built with `ImageResponse` from a mark shared with the share image. Off-site work is a local owner kit, not code.

**Tech Stack:** Next 16.4 App Router metadata API, `next/og` ImageResponse, Vitest 5 + Testing Library, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-01-brand-seo-design.md`

## Global Constraints

- No behaviour change outside the new /about page and its footer link (UI revamp = no behaviour change).
- Name `LandedNZ`; alternateName `Landed NZ`, `LandedNZ.co.nz`.
- bioShort: "Your step-by-step settling-in roadmap for New Zealand, checked against official sources."
- bioLong: bioShort + " Ask about any task and get answers cited from official New Zealand sites."
- Home title stays exactly "LandedNZ: your settling-in roadmap for New Zealand"; home description unchanged.
- No student-visa promise anywhere (D2). No persona names in copy.
- Raw hex only in files listed in `src/cw01.test.ts` EXEMPT.
- Commits: Conventional Commits with scope, no Co-Authored-By trailer.
- Per task: `npm test -w @landednz/web` + `npm run typecheck -w @landednz/web` + `npm run lint -w @landednz/web`. Full e2e once after all tasks.

## Review Focus

1. `sameAs` empty → the key is left out of the Organization, not `[]` (Task 2 test).
2. Home title must not become "… · LandedNZ" twice-branded once the template exists (Task 1 test).
3. Schema URLs are absolute and built from `SITE_URL`, never relative (Task 2 test).
4. The `<` escaping of JSON-LD stays when the graph grows (Task 2 test).
5. Footer with three links still fits the 36 px phone line at 390 px (Task 5 Playwright check).
