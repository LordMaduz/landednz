5 · The rules every page follows

Sizes

  • Only 24 (22 phone), 18, 16, 14, 12.
  • Every size maps to a published scale; see docs/design/type/standards.md.

Hierarchy

  • Weight does the work at 14–16: card headings are 600, rows 500, body 400.
  • Inside a card nothing is bigger than its featured heading.

One place

  • Roles live as type-* utilities in globals.css, phone sizes included.
  • Components use roles only; a test fails the build if one sets its own size or weight.
